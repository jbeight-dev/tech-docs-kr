    문서를 website-docs로 옮겼습니다

    제품, 배포, API, 개발 문서는 website-docs에서 통합 관리합니다. 이미 옮겼거나 중복되거나 낡은 예전 수기 문서는 삭제했으며, 과거 내용은 Git 이력에서 볼 수 있습니다.

    • 자주 묻는 질문과 업그레이드 문제 해결
    • API 레퍼런스
    • 개발 가이드
    • 마이그레이션 대응표와 남은 의존성

    이 디렉터리에는 다음 엔지니어링 리소스와 이 안내문만 남겨 둡니다.

    • docs.go, swagger.json, swagger.yaml과 계약 테스트: 백엔드 컴파일과 테스트에 쓰이며, 생성물은 여전히 make docs로 갱신합니다.
    • LITE.md: Lite 배포 패키지에 오프라인 README로 복사됩니다.
    • images/, assets/: README, Helm 등에서 아직 쓰는 이미지 리소스입니다.
    • poc/docker-sandbox/: 독립된 Go 실험 모듈입니다. 소스 코드와 실행 방법을 남겨 두지만 현재 제품 가이드는 아닙니다.

    이 리소스들은 아직 컴파일, 배포, 과거 실험 용도로 쓰이므로 디렉터리째 삭제하면 안 됩니다. 새 제품 설명은 더 이상 이곳에 두지 마십시오.
