    WeKnora Lite와 표준판의 차이

    Lite는 로컬에서 빠르게 쓰고 최대한 간단하게 배포하려는 경우를 위한 것이고, 표준판은 다중 스페이스 협업과 완전한 엔터프라이즈 기능을 위한 것입니다. 주요 차이는 다음과 같습니다.

    항목Lite표준판
    공유 스페이스공유 스페이스(멤버 초대, 멤버 간 지식베이스·에이전트 공유 등)를 제공하지 않음공유 스페이스와 스페이스 격리 검색 등 협업 기능 제공
    스페이스와 계정단일 스페이스. 설치 즉시 사용 가능, 가입 불필요다중 스페이스. 보통 가입, 로그인, 조직 관리 필요
    문서 파싱Simple 유형 파싱 엔진만 내장. Cloud 등으로 다른 파싱 기능 연결 가능여러 파싱 엔진(고정밀 포함)을 설정할 수 있고 완전한 문서 처리 경로와 통합
    배포 형태단일 애플리케이션, 무의존성(별도 데이터베이스, 메시지 큐 등 외부 서비스 스택에 의존하지 않음)보통 Docker Compose 등 다중 서비스 배포, 의존성과 구성 요소가 더 많음
    데이터 소유데이터를 전부 로컬에서 저장·처리프라이빗 배포라면 데이터를 로컬에 둘 수도 있음. 구체적인 배포 방식에 따라 다름
    네트워크 노출기본적으로 이 컴퓨터에서만 접근. 필요에 따라 설정해 공용 인터넷 허용 여부를 선택배포와 보안 정책에 따라 주소와 게이트웨이를 직접 바인딩

    여러 팀의 협업, 복잡한 파싱 파이프라인, 다중 서비스 아키텍처가 필요 없다면 개인이나 소규모 팀이 자기 컴퓨터에서 의존성 없이 써 보기에는 Lite가 더 적합합니다. 공유 스페이스, 다중 스페이스, 완전한 파싱 엔진 조합이 필요하면 표준판을 사용하십시오.

    설정 파일

    WeKnora-lite를 바로 실행하면 프로그램이 .env.lite를 자동으로 읽습니다. 먼저 프로그램이 있는 디렉터리(배포 패키지 압축을 푼 디렉터리 구조)에서 찾고, 다음으로 현재 디렉터리에서 찾으므로 직접 source할 필요가 없습니다. 배포 패키지의 .env.lite.example을 .env.lite로 복사하면 설정을 시작할 수 있습니다. 주의할 점:

    • 이 동작은 Lite로 빌드한 바이너리만 합니다. 표준판 바이너리는 어떤 dotenv 파일도 자동으로 읽지 않습니다.
    • 더 이상 .env로 보충하지 않습니다. .env.lite가 Lite의 유일한 파일 설정 출처입니다. 표준판 템플릿에 있는 REDIS_ADDR, Langfuse 자격 증명 같은 변수가 Lite의 인메모리 큐를 뜻하지 않게 바꾸거나 트레이싱을 켜는 일을 막기 위해서입니다.
    • 다른 파일을 지정하려면 ENV_FILE 환경 변수를 설정합니다(표준판에서도 동작합니다).
    • 명령줄이나 서비스 관리자에서 이미 설정한 환경 변수가 설정 파일보다 우선합니다.
    • .env.lite에 적은 LOG_LEVEL / LOG_PATH는 적용됩니다(파일을 불러온 뒤 로그 설정을 다시 적용합니다).
