    v0.9.0 릴리스 검토 기록

    상태: 문구, 문서, demo 실측 스크린숏, 릴리스 자료의 로컬 점검을 마쳤습니다. 동영상은 승인받은 원본 영상의 스타일을 이어받아 165초짜리 HTML 홍보 애니메이션으로 확장했고, 2026-10-28에 사용자 확인을 받았습니다. 릴리스 날짜는 2026-10-29로 확정했습니다. 정식 tag, 이미지 배포, 공식 웹사이트 배포는 아직 실행하지 않았습니다. 이전 라운드의 PR #4836은 머지됐으며, 이번 라운드에서는 검토 범위를 2026-10-29에 가져온 upstream main까지 넓히고 원래 기준선 이후의 릴리스 문서 차이를 보완했습니다.

    비교 기준선과 근거 이력

    • 지난 릴리스: v0.8.3, 2026-10-14, 3e22822c1d2397be730c458c7539d0eb8c113a24.
    • 이번 소스 기준선: c73c06b4b0a95ecec5f3b180311a4451f29d5103, 브랜치 chore/finalize-v0.9.0-release, 이미 머지된 PR #4836에 해당합니다. 목록은 이 소스 기준선까지이며 이번 라운드의 마무리 commit은 포함하지 않습니다. 최종 tag는 마무리 PR이 머지된 뒤의 commit으로 정해야 합니다.
    • 범위: commit 315개, 변경 경로 1929개. 전체 목록은 commit TSV와 파일 TSV에 있습니다. 이는 전체 commit/파일 차이 목록이며, 모든 비즈니스 코드를 한 줄씩 보안 감사했다는 뜻은 아닙니다.
    • 스타일: 홈페이지의 네 가지 핵심 항목은 왼쪽 글·오른쪽 그림으로 두고 네 단락 설명을 펼쳐 보입니다. 섹션 배경색은 번갈아 바꾸고, 브라우저 데모는 독립적으로 유지합니다. 기능 페이지는 먼저 용도와 단계를 설명한 뒤 필드/구현 참고를 둡니다. README의 각 릴리스 주제는 명확한 앵커로 바로 연결하고, 과거 버전 페이지는 그대로 둡니다.

    삭제하고 다시 쓴 내용

    이번에는 아직 유효한 용도가 있는 문서를 통째로 삭제하지 않았습니다. 현재 가이드에서 낡은 결론과 중복된 구현 세부 사항을 삭제했습니다. 삭제한 내용은 MCP만 승인이 필요하다는 설명, 모든 승인이 메모리에만 저장된다는 설명, 예전 이미지 파이프라인/트레이스 필드, 공유 할당이 0이면 손실 없이 강등할 수 있다는 설명, 그리고 장황한 DingTalk 경로 내부 구현 서술입니다. 어시스턴트 채팅 요청 필드는 assistant_access로, 일반 에이전트 설정 필드는 config.access_level로 바로잡아 자동화의 access_level과 혼동하지 않게 했습니다.

    문구 수정

    버전 설명은 「WeKnora 업무 어시스턴트」를 중심으로 용도를 소개합니다. 홈페이지 핵심 섹션 제목은 「WeKnora 어시스턴트, 멀티 에이전트 협업과 자동화」로 바꿨습니다. 네 가지 핵심 항목은 「WeKnora를 알려 주고 작업도 처리합니다」「여러 에이전트가 동시에 작업을 처리합니다」「한 문장으로 맡기거나 직접 설정할 수도 있습니다」「어떤 작업에 확인이 필요한지 정합니다」입니다. 첫 항목은 제품 질의응답, 페이지 컨텍스트, 현재 사용자 신분을 함께 설명하며, 어시스턴트와 자동화는 각각 전환 가능한 스크린숏 두 장을 씁니다. 홈페이지, 가이드, 버전 설명, 네 언어 README, CHANGELOG, 공지 본문을 모두 맞췄습니다. 동영상 도입부는 영어 「Your WeKnora assistant.」, 마무리는 「Ask. Create. Work together.」를 씁니다.

    홈페이지에서는 v0.8.3의 장기 기능을 해당 섹션으로 되돌렸습니다. 멀티모달 검색과 원문 위치 찾기는 RAG로, 첨부 파일 필요 시 읽기는 Agent로 옮겼고, Wiki 그래프와 이력은 Wiki에, Docker 터미널과 로컬 스킬은 스킬과 샌드박스에 그대로 두었습니다. 디렉터리 동기화는 데이터 소스로, 플랫폼 사용자 관리는 엔터프라이즈 관리로 옮겼습니다. 사용자의 후속 요청에 따라 새로 넣었던 「모델 연동과 관리」 단락을 삭제하고 기존 공급업체 소개를 유지했습니다. 상단의 주제를 넘나드는 「더 알아보기」 링크를 없애고, v0.9.0의 네 가지 핵심 항목을 독립적으로 유지했습니다. 갤러리는 지식베이스를 둘러보는 방식으로 따로 보여 주며 Wiki 앞에 둡니다. 사용자 요청에 따라 지난 버전의 갤러리 스크린숏 두 장을 그대로 쓰고 소재를 바꾸지 않았습니다.

    스크린숏과 동영상 출처

    스크린숏 여섯 장은 demo 계정과 「주말 독서 모임」 가상 자료를 썼으며, 크기는 1920 × 1056으로 이전 버전과 같은 20:11 비율을 유지합니다. 문서 사이트와 홈페이지 사본은 같습니다. 어시스턴트는 제품 질의응답과 작업 지원을, 자동화는 한 문장 설정과 직접 설정을 보여 주며, 협업과 승인은 카드 보기를 씁니다. 예전 갤러리 이미지는 그대로입니다. 입력 자료와 실측 범위는 데모 자료를 참고하십시오.

    동영상은 저장소 misc/intro-video/의 세리프 제목, 종이색 흰 배경, 짙은 남색과 금색, 흐르는 텍스트, 부드러운 전환을 이어받고, 현재 제품 소스 코드를 기준으로 각 기능을 다시 만들었습니다. 모든 화면은 HTML/CSS/SVG로 구성했고 공식 로고만 비트맵을 씁니다. 영상 속 리소스와 조작은 설명용 가상 예시이며 실제 실행이나 성능의 증거가 아닙니다.

    완성본은 165초, 1920 × 1080, 60 fps, H.264 / AAC이며, 영어 합성 음성 28구간, 영어 내장 자막 34줄과 별도 SRT를 포함하고 배경 음악은 없습니다. 715자의 타이핑 효과음은 입력과 동기화되며 사람 목소리가 나올 때 자동으로 볼륨을 낮춥니다. 표지는 네 가지 핵심 기능을 보여 주고, 이어서 제품 질의응답, 에이전트 생성, 이름 있는 협업, 자동화, 권한 승인, 백그라운드 산출물, Browser Skill, 갤러리, Wiki Graph, 원문 인용을 다룹니다. 생성은 페이지 팝업에서 어시스턴트로 들어가며, 승인 뒤에는 지식베이스 카드 이름이 바뀌는 모습을 보여 주고, 브라우저 플로팅 창은 페이지, 포커스, 커서를 동기화합니다. 소스 코드, 콘티, 재현 단계는 동영상 프로젝트를 참고하십시오.
