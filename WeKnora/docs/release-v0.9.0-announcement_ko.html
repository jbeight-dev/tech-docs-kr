    v0.9.0 릴리스 공지

    예정 릴리스 날짜: 2026-10-29. 아래 본문은 이번 릴리스 내용에 맞춰 정리해 두었으며, 정식 tag, 이미지, 공식 웹사이트에 모두 접근할 수 있게 된 뒤에 사용합니다. 공지는 아직 보내지 않았습니다.

    중국어 그룹 공지

    WeKnora v0.9.0이 나왔습니다! 이번 버전에는 어시스턴트, 멀티 에이전트 협업, 자동화 작업, 실행 권한 제어가 추가됐습니다.

    1. WeKnora 어시스턴트: WeKnora의 버전, 기능, 설정에 관한 질문에 답하고, 현재 페이지를 바탕으로 사용자 본인의 신분으로 에이전트를 만들고, 예약 작업을 설정하고, 지식을 정리하고, 설정을 조정합니다.
    2. 멀티 에이전트 협업: 수집, 정리, 검토를 여러 에이전트에 나눠 동시에 처리하고, 진행 상황과 결과를 각각 확인합니다.
    3. 자동화: 일회성 또는 주기적 계획을 설정해 정해진 시각에 요약을 만들고 자료를 정리합니다. 실행 기록에서 결과와 승인 대기 중인 작업을 확인합니다.
    4. 실행 권한과 승인: 읽기 전용, 수정 전 확인, 자동 실행 중에서 고르고, 확인 전에 구체적인 작업을 살펴봅니다. 삭제 같은 영향이 큰 작업은 여전히 승인을 받아야 합니다.
    5. 샌드박스와 지식 처리: 사용자별로 샌드박스를 재사용하는 선택적 방식과 백그라운드 Shell을 추가했고, 이미지 처리, Feishu / Lark 동기화, 표 파싱, 검색을 개선했습니다. 스페이스 관리자는 기본 모델과 웹 검색 서비스도 한곳에서 설정할 수 있습니다.

    업그레이드 전에 데이터베이스와 파일을 백업하고, 데이터베이스 마이그레이션, Feishu 재동기화, 샌드박스 재사용 조건을 중점적으로 확인하십시오. 전체 변경 사항과 업그레이드 요구 사항:

    • 버전 설명: https://weknora.weixin.qq.com/docs/07-releases/v0.9.0
    • 공식 웹사이트: https://weknora.weixin.qq.com/
    • GitHub: https://github.com/Tencent/WeKnora

    정식 이미지를 사용할 수 있게 되면 .env의 WEKNORA_VERSION을 0.9.0으로 설정하고, 같은 버전의 배포 파일로 갱신한 뒤 다음을 실행합니다.

    docker compose --profile full pull --policy always
docker compose --profile full up -d

    GitHub Issues로 문제를 알려 주시고, 개발자 그룹에서도 사용 경험을 나눠 주십시오.

    GitHub Release

    Title: WeKnora v0.9.0 — 어시스턴트, 멀티 에이전트 협업, 자동화

    WeKnora v0.9.0에 워크스페이스 어시스턴트가 추가됐습니다. 로고 옆에서 열어 WeKnora에 관해 묻거나 지금 보고 있는 페이지에서 바로 작업할 수 있습니다. 대화로 에이전트를 만들고, 반복 작업을 예약하고, 지식을 정리하고, 설정을 조정합니다. 여러 에이전트가 서로 다른 작업을 동시에 수행할 수 있고, 자동화는 일정에 따라 작업을 실행합니다. 읽기 전용, 쓰기 전 확인, 자동 실행 중에서 고르고, 승인이 필요한 작업을 검토하십시오. 이번 릴리스에는 워크스페이스 기본 모델, 선택적인 사용자별 샌드박스 재사용, 관리형 백그라운드 셸 작업, 설정 가능한 이미지 파이프라인, 더 넓은 데이터 소스 개선도 포함됩니다.

    릴리스 순서

    1. 이번 릴리스 마무리 PR을 머지하고 v0.9.0의 최종 commit을 확정합니다. 릴리스 날짜는 2026-10-29로 통일합니다. 검토 기준선 이후에 main이 계속 바뀌었다면 차이를 추가로 확인합니다.
    2. 프로젝트 버전 릴리스 절차를 마치고 v0.9.0 tag, 플랫폼별 산출물, 이미지를 사용할 수 있는지 확인합니다.
    3. 테스트 배포에서 마이그레이션과 핵심 기능 검수를 마친 뒤, 사이트 README에 따라 정적 패키지를 게시합니다.
    4. 공식 웹사이트의 버전 페이지, 스크린숏, 동영상, README 앵커를 확인하고 Release 본문과 그룹 공지를 게시합니다.

    이 문서는 릴리스 자료만 준비한 것이며, 위 작업이 이미 실행됐다는 뜻이 아닙니다.
