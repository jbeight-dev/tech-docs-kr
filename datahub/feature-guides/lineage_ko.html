    DataHub 리니지 소개

    기능 제공 범위: DataHub Core, DataHub Cloud

    데이터 리니지(data lineage)는 조직 내에서 데이터가 어떻게 흐르는지 보여 주는 지도입니다. 데이터가 어디에서 시작되어 어떻게 이동하고 최종적으로 어디에 도달하는지를 자세히 보여 줍니다. 이러한 흐름은 단일 시스템 내에서(Snowflake 테이블 간 데이터 이동 등) 또는 여러 플랫폼에 걸쳐 발생할 수 있습니다.

    직접 살펴보고 싶다면 아래의 대화형 투어를 진행한 뒤 자세한 내용을 읽어 보세요.

    데이터 리니지로 다음을 할 수 있습니다.

    • 데이터 무결성 유지
    • 복잡한 관계 단순화 및 정리
    • 리니지 영향 분석 수행
    • 리니지를 따라 메타데이터(예: 문서) 전파

    리니지 보기

    Lineage 탭의 Explorer 시각화나 Impact Analysis 도구에서 리니지를 볼 수 있습니다. 엔터티 사이드바에서 자산의 영향 분석을 한눈에 살펴볼 수도 있습니다.

    기본적으로 UI에는 최신 버전의 리니지가 표시됩니다. 시간 선택기를 사용하면 최신 버전 내에서 마지막 업데이트가 시간 범위를 벗어난 엣지를 제외할 수 있습니다. 시간 범위를 선택해도 과거 리니지가 표시되지는 않습니다. 최신 버전 리니지의 뷰만 필터링합니다.

    이 예시에서 데이터는 dbt가 오케스트레이션하는 여러 Snowflake 테이블을 거쳐 Looker 뷰와 explore로 흐릅니다.

    컬럼 수준 리니지

    컬럼 수준 리니지는 각 데이터 컬럼의 변경과 이동을 추적합니다. 이 방식은 테이블 수준에서 리니지를 지정하는 테이블 수준 리니지와 자주 대비됩니다. 테이블 수준 리니지를 보는 중에 테이블의 컬럼을 펼치고 리니지가 있는 컬럼에 마우스를 올리거나 클릭하면 컬럼 리니지를 시각화할 수 있습니다.

    숨겨진 자산에 대한 컬럼 수준 리니지가 있거나 테이블 수준 뷰가 너무 복잡해지면, 컬럼의 이동 경로(breadcrumb)를 클릭해 단일 컬럼에 초점을 맞춘 리니지를 시각화할 수 있습니다.

    데이터 파이프라인 리니지

    DataHub는 데이터 리니지와 함께 데이터 파이프라인의 태스크 관계 시각화도 지원합니다. 데이터 파이프라인의 엔터티 페이지에서 Lineage 탭으로 이동하면 시각화가 열립니다. 중앙에는 모든 구성 태스크를 포함하는 상자로 표현된 데이터 파이프라인 노드가 표시됩니다. 클릭하고 끌어서 상자 안의 각 태스크를 옮기거나 데이터 파이프라인 상자 자체를 옮길 수 있습니다.

    또한 DataHub의 크로스 플랫폼 리니지를 활용해 각 태스크의 업스트림과 다운스트림을 볼 수 있습니다. 리니지 펼치기 버튼의 숫자는 태스크의 데이터 의존성 업스트림/다운스트림 수를 나타냅니다. 펼친 뒤에는 표준 리니지 탐색기처럼 리니지를 계속 펼칠 수 있습니다.

    시각화를 단순하게 유지하기 위해 한 번에 한 태스크의 업스트림과 한 태스크의 다운스트림만 펼칠 수 있습니다.

    리니지 추가하기

    수집 소스

    리니지 추출을 지원하는 수집 소스(예: Table Lineage Capability)를 사용한다면 리니지 정보를 자동으로 추출할 수 있습니다. 자동 리니지 추출을 지원하는 소스 목록은 여기에서 확인할 수 있습니다. 자세한 지침은 사용 중인 소스의 소스 문서를 참고하세요.

    UI

    v0.9.5부터 DataHub는 엔터티 간 리니지의 수동 편집을 지원합니다. 데이터 전문가는 리니지 시각화 화면과 엔터티 페이지의 Lineage 탭에서 업스트림 및 다운스트림 리니지 엣지를 자유롭게 추가하거나 제거할 수 있습니다. 자동 리니지 추출을 보완하거나, 자동 추출을 지원하지 않는 소스에서 중요한 엔터티 관계를 설정하는 데 이 기능을 사용하세요. 수동 리니지 편집은 Datasets, Charts, Dashboards, Data Jobs에서 지원합니다. 자세한 내용은 리니지 UI 가이드를 참고하세요.

    주의: UI 기반 리니지 관련 권장 사항

    수동으로 추가한 리니지와 프로그래밍 방식으로 추가한 리니지가 서로 충돌해 원치 않는 덮어쓰기가 발생할 수 있습니다. 수집 소스 실행 등으로 리니지 정보를 자동 추출하지 않는 경우에만 리니지를 수동으로 편집할 것을 강력히 권장합니다. 리니지가 자동으로 수집되는 엔터티의 리니지를 수동으로 편집하려면, 해당 수집 소스가 incremental_lineage를 지원하는지 확인하고 지원한다면 이 구성 플래그를 활성화하는 것을 고려하세요. 이 플래그를 설정하면 이전에 존재하던 리니지 엣지가 제거되지 않으므로, 현재 리니지를 정확히 파악하려면 시간 기반 필터링을 사용해야 할 수 있습니다.

    API

    리니지를 지원하는 수집 소스를 사용하지 않는다면 API로 엔터티 간 리니지 엣지를 프로그래밍 방식으로 내보낼 수 있습니다. 자세한 내용은 리니지 API 가이드를 참고하세요.
