    DataHub Applications 소개

    기능 제공 범위: DataHub Core, DataHub Cloud

    DataHub Cloud v1.2.0에는 특정 비즈니스 목적에 부합하는 유사한 자산을 DataHub 안에서 묶는 방식인 Applications가 도입되었습니다.

    Applications는 DataHub 메타데이터 모델 계층에서 Domains와 Data Products 사이에 위치합니다.

    • Domains(가장 큼): 여러 목적을 가진 비즈니스 영역
    • Applications(중간): Domain 내의 단일 비즈니스 목적
    • Data Products(가장 작음): Application 내의 구체적인 데이터 제공물

    예를 들어 전자상거래 회사의 구조는 다음과 같을 수 있습니다.

    • Payments Domain: 비즈니스 전반의 결제 처리와 관련된 모든 것을 포함합니다
    • Refund Application: Payments Domain에서 고객 환불 처리에 특별히 사용되는 모든 자산을 묶으며, 다음을 포함합니다.
      • "Daily Refund Payments" Data Product
      • "Daily Refund Failures" Data Product
      • 결제 파이프라인, 환불 처리 데이터셋 등의 지원 자산
    • Fraud Detection Application: Payments Domain에서 사기 거래의 식별과 방지에 관련된 모든 자산을 묶으며, 다음을 포함합니다.
      • "Real-time Fraud Alerts" Data Product
      • "Weekly Fraud Analytics Report" Data Product
      • ML 모델, 위험 점수 데이터셋 등의 지원 자산

    각 Application은 더 넓은 Payments Domain의 일부이면서 고유한 비즈니스 목적을 수행합니다.

    Applications를 사용하는 이유

    Applications는 이미 내부적으로 이 개념을 사용하고 있으며 Domains와 Data Products 외에 추가적인 구조가 필요한 대규모 조직에 가장 적합합니다. 대부분의 팀에는 Domains와 Data Products부터 시작하기를 권장합니다.

    다음 사항을 염두에 두세요.

    • Applications는 Data Mesh 아키텍처의 일부가 아닙니다 — 일부 대규모 조직에 유용한 추가 조직 계층이지만, Data Mesh를 도입하는 팀에는 적합하지 않습니다
    • Applications는 소프트웨어 서비스와 다릅니다 — 서비스는 하나의 소프트웨어인 반면, DataHub의 Application은 하나의 비즈니스 목적을 중심으로 여러 데이터 자산을 묶습니다

    참고

    대부분의 팀에는 Applications가 필요하지 않습니다. DataHub 사용자에게는 Domains와 Data Products만으로 충분한 경우가 많습니다.

    사전 요구 사항과 권한

    Applications를 사용하려면 다음 DataHub 권한이 필요합니다.

    • 새 Application을 만들거나 기존 Application을 편집하려면 Applications에 대한 Edit Entity 권한이 필요합니다.
    • 데이터 자산에 Application을 할당하려면 Edit Entity Applications 권한이 필요합니다.
    • 사용자에게 Applications를 표시할지 제어하려면 Manage Features 플랫폼 권한이 필요합니다.

    이러한 권한을 활용하는 커스텀 정책을 만드는 방법은 여기에서 자세히 알아보세요.

    Applications 사용하기

    Applications 활성화

    Applications를 활성화하려면 DataHub 담당자와 함께 기능을 구성해야 합니다. 구성이 완료되면 Settings > Appearance로 이동해 Show Applications를 켜세요.

    참고

    Applications는 기본적으로 비활성화되어 있습니다. 기능을 활성화하려면 DataHub 담당자에게 문의하세요.

    Application 만들기

    Application을 만들려면 먼저 DataHub 왼쪽 탐색 메뉴의 Applications 탭으로 이동합니다.

    Applications 페이지에서는 DataHub에 생성된 모든 Application의 목록을 볼 수 있습니다.

    새 Application을 만들려면 '+ Create Application'을 클릭합니다.

    양식에서 Application의 이름, 설명, 소유자를 지정할 수 있습니다. API로 Application을 만드는 방법은 이 튜토리얼에서 자세히 알아보세요.

    Application에 자산 할당하기

    UI를 사용하거나 API로 프로그래밍 방식으로 Application에 자산을 할당할 수 있습니다. UI에서는 Entity 사이드바나 Applications 페이지에서 Application을 추가할 수 있습니다.

    API로 Application에 자산을 할당하는 방법은 이 튜토리얼에서 자세히 알아보세요.

    Application으로 검색하기

    Application을 만들면 검색창에서 찾을 수 있습니다.

    검색 결과를 클릭하면 Application 프로필로 이동하며, 여기에서 설명을 편집하고 소유자를 관리하고 Application 내부의 자산을 볼 수 있습니다.

    Application에 자산을 추가하면 검색 필터를 사용해 검색 결과를 특정 Application 내의 자산으로 제한할 수 있습니다.
