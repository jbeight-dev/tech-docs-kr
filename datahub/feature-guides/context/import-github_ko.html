    GitHub에서 가져오기

    기능 제공 범위: DataHub Cloud 전용

    개요

    GitHub 리포지토리의 Markdown 및 텍스트 파일을 DataHub의 Context Documents로 가져옵니다. 폴더 계층 구조는 유지됩니다.

    기본적으로 가져온 문서는 Native(DataHub에서 편집 가능)입니다. GitHub에 연결된 읽기 전용 문서를 원하면 Document import mode를 External로 전환하세요. DataHub Cloud에서는 선택적으로 역동기화(sync-back)를 활성화해 DataHub 편집 내용을 같은 리포지토리로 푸시할 수 있습니다(Native 모드).

    사전 요구 사항

    • 테넌트 GitHub App(권장) 또는 개인 액세스 토큰을 통한 대상 리포지토리 접근 권한(읽기 권한, DataHub Cloud에서 역동기화를 사용하면 쓰기 권한)
    • DataHub에서 Data Sources / 수집을 관리할 수 있는 권한

    가져오기 설정

    1. Documents → Import → GitHub를 엽니다.
    2. 인증합니다(GitHub App 또는 개인 액세스 토큰).
    3. 리포지토리, 브랜치, 선택적 경로 접두사 / 파일 확장자, Document import mode(Native 또는 External)를 설정합니다.
    4. 선택적으로 Sync edits back to GitHub를 활성화합니다(DataHub Cloud만 해당, pull request 또는 직접 커밋과 충돌 정책 설정).
    5. 저장하고 소스를 실행(또는 예약)합니다.

    스크린샷: GitHub 가져오기 / 데이터 소스 구성(역동기화 옵션 포함).

    역동기화(선택 사항, DataHub Cloud만 해당)

    정보: DataHub Cloud만 해당

    역동기화는 DataHub Cloud(github-documents-cloud)에서만 사용할 수 있습니다. 오픈소스 github-documents 가져오기는 변경 사항을 GitHub에 다시 쓰지 않습니다.

    활성화하면 각 실행은 먼저 GitHub에서 가져온 다음, 대기 중인 DataHub 변경 사항을 보통 pull request(권장) 또는 직접 커밋으로 다시 씁니다. 동시 편집은 충돌 정책(머지, DataHub 우선, 건너뛰기)에 따라 처리됩니다.

    실행 기록 보기

    Data Sources(Ingestion)를 열어 역동기화 결과를 포함한 실행, 일정, 실패를 확인합니다.
