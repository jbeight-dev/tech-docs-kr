    Views

    기능 제공 범위: DataHub Core, DataHub Cloud

    Views를 사용하면 필터 집합을 저장해 DataHub 전체에서 재사용할 수 있습니다. View를 활성화하면 검색 결과, 찾아보기 페이지, 추천, 기타 자산 목록이 일치하는 자산으로 자동으로 좁혀집니다.

    Views를 사용하는 이유

    • 중요한 것에 집중 — 팀이 소유하거나, 특정 도메인에 속하거나, 특정 플랫폼에 있는 자산만 표시합니다.
    • 새 사용자의 빠른 온보딩 — 조직 전체 기본값을 설정해 새 사용자가 큐레이션된 관련 카탈로그 범위에서 시작하게 합니다.
    • AI 에이전트 범위 지정 — 서비스 계정에 View를 할당해 MCP 서버 검색이 정의된 경계 안에 머물게 합니다.

    공개 뷰와 개인 뷰

    유형 표시 대상 만들 수 있는 사람 설정 가능한 기본값
    Public (Global) 모든 사용자 관리자만 사용자, 조직, 서비스 계정 기본값
    Personal (Private) 생성자만 모든 사용자 사용자 기본값만

    모든 사용자는 자신이 사용할 개인 뷰를 만들 수 있습니다. 공개 뷰는 조직 전체에 공유되며 Manage Public Views 플랫폼 권한이 필요합니다. 이 권한은 기본적으로 관리자에게 부여됩니다.

    View 만들기

    1. 검색창의 View selector를 클릭합니다
    2. + Create View를 클릭하고 Public 또는 Personal을 선택합니다
    3. View 이름을 지정하고, 필터(엔터티 유형, 플랫폼, 도메인, 태그, 소유자 등)를 선택한 뒤 Save를 클릭합니다

    검색 결과 페이지에서 현재 검색 필터를 View로 바로 저장할 수도 있습니다.

    View 편집 및 삭제

    View selector를 열고 View 옆의 ... 메뉴를 클릭해 이름을 바꾸거나, 필터를 업데이트하거나, 삭제합니다. 개인 뷰는 생성자만 수정할 수 있습니다. 공개 뷰는 Manage Public Views 권한이 있는 관리자가 관리할 수 있습니다.

    View가 적용되는 위치

    활성 View는 검색 결과, 홈 페이지, 도메인 페이지, 데이터 제품 페이지, 빠른 필터, 탐색 모음의 엔터티 수에 표시되는 내용을 필터링합니다.

    기본 뷰

    DataHub를 열거나, Ask DataHub 대화를 시작하거나, MCP 서버로 쿼리할 때마다 자동으로 적용되도록 기본 View를 설정할 수 있습니다. 기본값은 두 수준에서 동작합니다.

    개인 기본값

    모든 사용자는 ... 메뉴 > Make my default로 자신의 기본값을 선택할 수 있습니다. 공개 또는 개인 View 중 어느 것이든 가능합니다.

    개인 기본값은 항상 조직 기본값보다 우선합니다.

    조직 기본값

    관리자는 ... 메뉴 > Make organization default로 하나의 공개 View를 조직 전체 기본값으로 지정할 수 있습니다. 자신의 기본값을 선택하지 않은 모든 사용자에게 적용됩니다. Manage Public Views 권한이 필요합니다.

    세션 중에는 언제든 활성 View를 전환하거나 지울 수 있습니다.

    Ask DataHub의 Views

    Ask DataHub에서 채팅 입력란 옆의 View selector를 클릭해 개인 또는 공개 View를 선택합니다. 해당 View가 대화 중 AI 어시스턴트의 모든 검색 범위를 지정합니다.

    View를 선택하지 않으면 조직 기본값(설정된 경우)이 사용됩니다.

    참고: Slack 및 Microsoft Teams

    Slack과 Microsoft Teams에서는 조직 기본 View가 항상 자동으로 적용됩니다.

    서비스 계정의 Views

    서비스 계정에 View를 할당하면 MCP 서버를 통한 모든 검색의 범위를 해당 View로 지정할 수 있습니다.

    1. Settings > Users & Groups > Service Accounts로 이동합니다
    2. Default View 드롭다운에서 공개 뷰를 선택합니다

    서비스 계정에 뷰가 설정되어 있지 않으면 조직 기본값이 대신 사용됩니다.

    정보: 공개 뷰만 가능

    서비스 계정에는 공개(전역) 뷰만 할당할 수 있습니다. 개인 뷰는 지원하지 않습니다.

    사용 사례 예시:

    • 마케팅 팀의 AI 에이전트에 "Marketing Data" View를 할당합니다.
    • 에이전트가 프로덕션 자산만 검색하도록 "Production Only" View를 만듭니다.
    • 에이전트를 Snowflake 같은 단일 플랫폼으로 제한합니다.

    View 관리

    Settings > My Views로 이동하면 모든 개인 뷰와 공개 뷰를 한곳에서 볼 수 있습니다. 여기에서 만들기, 편집, 삭제, 기본값 변경을 할 수 있습니다.

    권한

    작업 수행할 수 있는 사람
    개인 뷰 만들기 모든 사용자
    공개 뷰 만들기 Manage Public Views가 있는 관리자
    개인 뷰 편집 / 삭제 해당 뷰를 만든 사용자
    공개 뷰 편집 / 삭제 Manage Public Views가 있는 관리자
    개인 기본값 설정 모든 사용자(본인 대상)
    조직 기본값 설정 Manage Public Views가 있는 관리자
    서비스 계정 기본 뷰 설정 Manage Service Accounts가 있는 관리자

    고급 사용법

    CLI나 GraphQL API를 직접 사용할 때는 기본 View가 자동으로 적용되지 않으므로 View URN을 명시적으로 전달해야 합니다.

    CLI

    검색할 때 --view 플래그를 사용합니다.

    datahub search "*" --view "urn:li:dataHubView:my-view-id"

    자세한 내용은 CLI 검색 문서를 참고하세요.

    GraphQL API

    검색 쿼리에 viewUrn 매개변수를 전달합니다.

    {
  searchAcrossEntities(
    input: { query: "*", count: 10, viewUrn: "urn:li:dataHubView:my-view-id" }
  ) {
    total
    searchResults {
      entity {
        urn
        type
      }
    }
  }
}

    viewUrn은 searchAcrossEntities, scrollAcrossEntities, aggregateAcrossEntities, browseV2, 기타 검색 관련 쿼리에서 지원합니다.
