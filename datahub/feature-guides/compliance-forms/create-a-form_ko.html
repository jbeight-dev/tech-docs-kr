    DataHub Compliance Form 만들기

    기능 제공 범위: DataHub Core, DataHub Cloud

    이 가이드에서는 Compliance Form을 만들고 할당하는 다음 과정을 설명합니다.

    1. 새 Compliance Form 만들기
    2. Compliance Form의 Questions 작성
    3. Compliance Form의 Assets 할당
    4. Compliance Form의 Assignees 선택
    5. Compliance Form 게시

    참고

    DataHub UI에서 Compliance Form을 관리하는 기능은 DataHub Cloud에서만 사용할 수 있습니다. DataHub Core를 사용한다면 Compliance Forms API 가이드를 참고하세요.

    사전 요구 사항

    Compliance Form을 만들거나 편집하거나 제거하려면, 또는 자산에 할당하려면(동적 할당 필터 포함) Manage Compliance Forms 플랫폼 권한이 있어야 합니다.

    참고: API 동등성

    UI와 GraphQL mutation(batchAssignForm, batchRemoveForm, createDynamicFormAssignment)을 통해서는 Manage Compliance Forms만으로 양식을 할당할 수 있습니다. OpenAPI, Rest.li, CLI 메타데이터 이미터로 forms 또는 dynamicFormAssignment aspect를 직접 쓰려면 대상에 대한 Edit Entity도 추가로 필요합니다. 이러한 API는 모든 aspect 쓰기를 일반 엔터티 업데이트로 간주해 권한을 확인하기 때문입니다(REST API 권한 부여가 비활성화된 경우 제외). 자신에게 이미 할당된 양식을 완료하거나 검증할 때는 어떤 API에서도 Manage Compliance Forms가 필요하지 않습니다.

    1단계: 새 Compliance Form 만들기

    탐색 모음에서 Govern > Compliance Forms로 이동합니다. + Create를 클릭해 양식 작성을 시작합니다.

    먼저 다음 세부 정보를 입력합니다.

    1. Name: Compliance Form의 목적을 명확히 전달하는 고유하고 설명적인 이름을 선택합니다. 예를 들면 "PII Certification Q4 2024"입니다.

      전문가 팁: 이 이름은 작업을 할당받은 담당자에게 표시되므로, 양식의 의도가 효과적으로 전달되도록 명확하고 자세하게 작성하세요.

    2. Description: Compliance Form의 목적을 설명하는 간결하면서 유익한 설명을 작성합니다. 이니셔티브의 중요성, 목표, 예상 완료 일정 같은 핵심 세부 정보를 포함하세요. 담당자가 프로세스에서 자신의 역할과 그 맥락 및 중요성을 이해하는 데 도움이 됩니다.

      예시: "이 Compliance Form은 PII가 포함된 모든 데이터셋을 2024년 4분기까지 검토하고 검증하기 위해 마련되었습니다. 조직 및 규제 요구 사항을 준수하려면 이 양식을 반드시 완료해야 합니다."

    3. Type: 컴플라이언스 요구 사항에 따라 양식의 수집 유형을 지정합니다.

      • Completion: 선택한 자산의 모든 필수 질문에 답변하면 양식이 완료된 것으로 간주됩니다. 기본적인 요구 사항 완료 사용 사례에 이 옵션을 권장합니다.

      • Verification: 선택한 자산의 모든 필수 질문에 답변하고 그리고 담당자가 응답을 명시적으로 "검증"해야만 양식이 완료된 것으로 간주됩니다. 담당자의 최종 승인이 필요해 응답의 정확성과 유효성을 확인받아야 할 때 이 옵션을 권장합니다.

    4. 다음으로 Add Question을 클릭해 양식의 요구 사항 작성을 시작합니다.

    2단계: 양식의 질문 작성

    다음으로 Compliance Form의 질문을 정의합니다. 질문은 선택한 자산에 관한 필수 정보를 수집하는 데 사용되며, 양식이 완료된 것으로 간주되려면 담당자가 질문을 완료해야 합니다.

    다음 5가지 질문 유형 중에서 선택할 수 있습니다.

    • Ownership: 선택한 자산에 하나 이상의 소유자를 할당하도록 요청합니다. 선택적으로 유효한 사용자, 그룹, 소유권 유형의 특정 집합으로 응답을 제한할 수 있습니다.
      • 예: 이 데이터셋의 정확성을 보장할 책임은 누구에게 있나요?
    • Domain: 자산에 도메인을 할당하며, 허용되는 도메인 집합을 미리 정의할 수 있습니다.
      • 예: 이 대시보드는 어느 도메인에 속하나요? Sales, Marketing, Finance.
    • Documentation: 자산 또는 컬럼(또는 둘 다)에 대한 문서를 제공합니다.
      • 예: 이 데이터셋의 주요 사용 사례는 무엇인가요? 다른 사람들이 알아야 할 주의 사항은 무엇인가요?
    • Glossary Terms: 자산 또는 컬럼(또는 둘 다)에 하나 이상의 용어집 용어를 할당하며, 허용되는 용어집 용어 집합을 미리 정의할 수 있습니다.
      • 예: 이 자산에 어떤 유형의 개인 식별 정보(PII)가 포함되어 있나요? Email, Address, SSN 등.
    • Structured Properties: 자산 또는 컬럼(또는 둘 다)에 커스텀 속성을 적용합니다.
      • 예: 이 데이터셋은 언제 사용 중단되고 삭제되나요?

    질문을 만들 때는 담당자가 이해하기 쉽도록 명확하고 간결한 제목을 사용합니다. 설명에는 응답을 안내하는 추가 컨텍스트나 지침을 포함합니다. 제목과 설명은 양식을 완료할 때 담당자에게 모두 표시되므로, 질문에 정확하고 자신 있게 답하는 데 필요한 구체적인 힌트나 세부 정보를 제공하세요.

    3단계: Compliance Form에 자산 할당

    담당자가 완료할 질문을 정의했으니 이제 이 작업의 범위에 포함되는 자산을 할당합니다.

    Assign Assets 섹션에서 다음 단계에 따라 이 양식과 관련된 특정 자산 집합을 쉽게 지정할 수 있습니다.

    1. 조건 또는 조건 그룹을 추가합니다
    2. 다음과 같은 적절한 필터 유형을 선택합니다.
      • Asset Type(Dataset, Chart 등)
      • Platform(Snowflake, dbt 등)
      • Domain(Sales, Marketing, Finance 등)
      • Assigned Owners
      • Assigned Glossary Terms
    3. 필터를 All, Any, None 중 어떤 방식으로 적용할지 결정합니다
    4. 관련 자산을 미리 보고 적절한 필터를 적용했는지 확인합니다

    예를 들어 Finance Domain에도 연결된 모든 Snowflake Datasets에 집중하도록 필터를 적용할 수 있습니다. 이렇게 하면 컴플라이언스 이니셔티브를 관리 가능한 단위로 나눌 수 있으므로 전체 데이터 생태계를 한 번에 처리하지 않아도 됩니다.

    4단계: Compliance Form을 완료할 담당자 선택

    질문과 할당된 자산을 정의했으면 다음 단계는 양식 완료를 담당하는 사용자 또는 그룹, 즉 담당자를 선택하는 것입니다.

    Add Recipients 섹션에서 양식 완료 담당자를 결정합니다.

    • Asset Owners: 범위 내 자산 중 하나에 할당된 모든 사용자가 양식을 완료할 수 있습니다. 전체 사용자 집합을 알 수 없는 대규모 이니셔티브에 유용합니다. 선택적으로 할당을 특정 소유권 유형(Technical Owner, Data Steward, Business Owner, 커스텀 소유권 유형)으로 제한할 수 있습니다. 유형을 선택하지 않으면 유형과 관계없이 모든 소유자가 할당됩니다.
    • Specific Users and/or Groups: DataHub 내의 특정 사용자 또는 그룹 집합을 선택합니다. 자산의 소유권이 제대로 정의되어 있지 않을 때 유용합니다.

    또한 알림 기본 설정을 구성할 수 있습니다.

    • Send notifications to assignees when this form is published: 양식을 사용할 수 있게 되면 담당자에게 자동으로 알리려면 이 옵션을 선택합니다. 활성화하면 담당자는 DataHub Task Center에서 작업을 볼 수 있을 뿐 아니라(DataHub Cloud만 해당), 구성된 채널(DataHub Cloud의 이메일 또는 Slack)로도 알림을 받습니다.

    5단계: 양식 게시

    질문을 정의하고, 자산을 할당하고, 담당자를 선택하면 양식을 게시할 준비가 된 것입니다.

    게시하면 다음이 수행됩니다.

    • 담당자의 DataHub Task Center에 작업이 대기합니다(DataHub Cloud만 해당)
    • 알림을 활성화했고 담당자가 이메일 또는 Slack 알림을 구성했다면(DataHub Cloud만 해당) 해당 채널로 알림을 받습니다
    • 시간이 지나 새로운 자산이 양식의 대상이 되면, 새 소유자에게 자동으로 알림이 전송되고 양식이 할당됩니다

    양식을 게시하려면 Publish를 클릭하기만 하면 됩니다.

    주의

    양식을 게시한 뒤에는 질문을 변경하거나 추가할 수 없습니다. 다만 양식의 자산과 담당자 집합은 변경할 수 있습니다.

    FAQ 및 문제 해결

    Compliance Form 질문에 답변하면 선택한 자산이 업데이트되나요?

    예! Compliance Forms는 핵심 데이터 자산의 주요 속성을 대규모로 수집하고 업데이트하는 강력한 도구입니다. 질문에 답변하면 응답이 선택한 자산의 해당 속성을 직접 업데이트합니다.

    Compliance Form은 기존 메타데이터와 어떻게 상호작용하나요?

    양식 질문에서 참조하는 메타데이터가 자산에 이미 있으면, 담당자는 기존 값을 확인하거나, 덮어쓰거나, 추가 세부 정보를 덧붙일 수 있습니다.

    자세한 내용과 예시는 양식 완료하기 가이드에서 확인할 수 있습니다.

    Completion Form과 Verification Form의 차이점은 무엇인가요?

    두 양식 유형 모두 DataHub 사용자가 완료할 선택 및 필수 질문 집합을 구성하는 방법입니다. Verification Form을 사용하면 모든 필수 질문을 완료한 뒤 사용자에게 최종 검증 단계가 표시됩니다. 제출한 정보의 정확성에 대한 최종 확인으로 생각하면 됩니다.

    하나의 자산에 여러 양식을 할당할 수 있나요?

    물론입니다! 다만 할당된 모든 양식의 필수 질문을 모두 완료해야만 자산이 Documented 또는 Verified로 간주된다는 점에 유의하세요.

    DataHub 사용자는 Compliance Form이 할당되었음을 어떻게 알 수 있나요?

    담당자는 여러 방식으로 알림을 받습니다.

    • DataHub Task Center에 작업이 표시됩니다(DataHub Cloud만 해당)
    • 양식을 게시할 때 알림을 활성화했고 담당자가 이메일 또는 Slack 알림을 구성했다면(DataHub Cloud만 해당) 해당 채널로 알림을 받습니다
    • 새로운 자산이 기존 양식의 대상이 되면, 새 소유자에게 자동으로 알림이 전송되고 양식이 할당됩니다

    양식 완료 진행 상황은 어떻게 추적하나요?

    좋은 질문입니다. 선택한 자산 전반에 걸친 이니셔티브의 진행 상황을 직접 보여 주는 Compliance Forms Analytics를 작업 중입니다. 기대해 주세요!
