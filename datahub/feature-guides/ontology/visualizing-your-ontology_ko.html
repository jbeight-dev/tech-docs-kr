    온톨로지 시각화하기

    기능 제공 범위: DataHub Cloud 전용 · 비공개 베타

    그래프를 사용하면 목록에서는 찾기 어려운 것을 쉽게 발견할 수 있습니다. 어떤 개념이 중심에 있고, 어떤 개념이 고립되어 있으며, 두 팀이 같은 개념을 어디에서 중복으로 모델링했는지 알 수 있습니다.

    DataHub는 같은 그래프에 대해 전체 용어집을 보여 주는 전역 뷰와 하나의 용어를 중심으로 하는 집중 뷰를 제공합니다.

    DataHub Cloud v2.2.1 이상에서 사용할 수 있습니다.

    전역 뷰

    왼쪽 사이드바에서 Govern → Ontology로 이동합니다. 하나 이상의 관계에 참여하는 모든 용어집 용어가 자동으로 배치되어 표시됩니다.

    관계가 전혀 없는 용어는 숨겨집니다. 관계 그래프에서 아무 정보도 제공하지 않으며, 숨기면 레이아웃을 읽기 쉽게 유지할 수 있기 때문입니다. 하단의 정보 표시줄에 제외된 용어 수가 표시됩니다.

    왼쪽 상단에는 두 가지 컨트롤이 있습니다.

    • Search는 쿼리와 일치하는 용어와 그에 연결된 용어로 그래프를 필터링합니다. 검색창의 위/아래 화살표로 일치 항목을 차례로 이동하면 그래프가 각 항목으로 이동합니다.
    • Relationship types는 특정 관계 유형으로 그래프를 필터링합니다. 예를 들어 Inherits만 선택하면 그래프가 개념 분류 체계로 축소되고 나머지는 숨겨집니다. 각 유형에는 해당 유형의 엣지 수가 표시됩니다.

    참고

    용어집이 크면 첫 렌더링을 빠르게 유지하기 위해 초기 뷰의 용어 수를 고정된 값으로 제한합니다. 제한이 적용되면 정보 표시줄에 표시됩니다. 개별 노드를 펼치거나, 검색하거나, 관계 유형으로 필터링하면 그 범위를 넘어갈 수 있습니다.

    그래프 읽기

    • 각 노드는 용어집 용어입니다. 노드를 클릭하면 세부 정보가 열리고, 노드의 Expand를 클릭하면 현재 그려지지 않은 이웃을 가져옵니다. 그려진 것보다 이웃이 많은 노드에는 개수 배지가 표시됩니다.
    • 각 엣지는 관계이며, 유형별로 레이블과 색상이 지정됩니다(Is A, Has A, Is Synonym Of, Is Related To, 커스텀 유형). 방향이 있는 엣지는 소스에서 대상을 가리키는 화살표로 그려집니다. 엣지에 마우스를 올리면 유형, 방향 여부, 전이성 여부를 볼 수 있습니다.

    참고

    엣지 레이블은 기반 관계 유형 이름(Is A, Has A)을 사용하지만, Related Terms 탭은 같은 관계에 대해 더 친숙한 표시 이름(Inherits, Contains)을 사용합니다.

    집중 뷰

    모든 용어집 용어에는 해당 용어를 중심으로 같은 그래프를 보여 주는 Relationships 탭이 있습니다.

    Customer에 의존하는 것은 무엇인가?, Revenue는 무엇과 연결되는가?처럼 하나의 개념에 관한 질문에 답할 때 사용하는 뷰입니다. 중심 용어에는 Home 배지가 표시되며, 그래프는 한 홉 범위에서 시작합니다. 이웃을 펼치면 더 멀리 따라갈 수 있습니다.

    탭은 하나의 용어에 고정되어 있으므로 여기에서는 검색이 숨겨집니다. 관계 유형 필터는 계속 적용됩니다.

    집중 뷰로 바로 연결되는 딥 링크를 사용할 수도 있으며, 전체 너비의 Ontology 페이지에서 같은 그래프가 열립니다.

    https://<your-datahub>/ontology?urn=urn:li:glossaryTerm:customer

    Related Terms와 Relationships 비교

    용어집 용어에는 관계를 보여 주는 탭이 두 개 있습니다.

    • Related Terms는 관계 유형별로 묶인 표 형식 뷰입니다. 편집을 지원하며, 여기에서 관계를 추가하고 제거합니다.
    • Relationships는 그래프 뷰입니다. 읽기 전용이지만 여러 홉을 보여 주므로 용어에서 바깥쪽으로 탐색할 수 있습니다.

    빈 상태

    그래프가 비어 있으면 다음 중 하나에 해당합니다.

    • "No glossary terms yet" — 용어집 자체가 비어 있습니다. 먼저 용어를 만드세요.
    • "No relationships between glossary terms" — 용어는 있지만 관계가 없습니다. 용어집 용어 연결하기를 참고하세요.
    • "No relationships yet"(집중 뷰) — 다른 용어에는 관계가 있지만 이 용어에는 없습니다.
    • "No matching glossary terms" — 검색 또는 관계 유형 필터로 모든 항목이 제외되었습니다.

    이 기능 활성화하기

    인스턴스에서 활성화하려면 DataHub 담당자에게 문의하세요.

    자체 관리 배포에서는 GMS에 플래그를 설정하고 재시작합니다.

    SHOW_ONTOLOGY_GRAPH=true

    또는 Helm을 사용합니다.

    datahub-gms:
  showOntologyGraph: true
