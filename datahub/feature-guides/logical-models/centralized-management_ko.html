    중앙 집중식 관리

    기능 제공 범위: DataHub Cloud 전용

    정보

    이 기능은 현재 DataHub Cloud에서 비공개 베타입니다. 자세한 내용은 DataHub Cloud 담당자에게 문의하세요.

    동작 방식

    중앙 집중식 관리(Centralized Management)를 사용하면 논리 상위 수준에서 모든 물리 하위 항목을 거버넌스할 수 있습니다. 즉, 논리 모델의 메타데이터 변경 사항이 모든 물리 하위 항목으로 전파됩니다.

    논리 수준의 메타데이터물리 수준의 변경
    Tags✅ 태그가 물리 하위 항목에 복제됩니다.
    Glossary Terms✅ 용어가 물리 하위 항목에 복제됩니다.
    Documentation✅ 논리 상위 항목에 표시된 설명이 물리 하위 항목에 복사됩니다. 하위 항목에 자체 설명이 있으면 그 설명이 대신 표시됩니다.
    Ownership✅️ 소유자가 물리 하위 항목에 복제됩니다. 같은 사용자가 여러 소유권 유형의 소유자이면 하나의 소유권 유형만 복제됩니다.
    Structured Properties✅ 구조화된 속성이 물리 하위 항목에 복제됩니다. 하위 항목에 같은 속성의 기존 값이 있으면, 다중 값 속성이더라도 교체됩니다.
    Domains✅ 도메인이 물리 하위 항목에 복제됩니다. 전파된 도메인은 기존 도메인을 덮어쓰지 않으며, 사용자가 설정한 도메인이 제거될 때까지 숨겨진 상태로 유지됩니다.
    Data Products❌ 데이터 제품은 전파되지 않습니다.
    Data Quality Assertions❌ Assertion은 전파되지 않습니다.

    전파된 속성에 마우스를 올리면 이 정보가 언제 어디에서 왔는지 확인할 수 있습니다.

    시작하기

    중앙 집중식 관리에는 하나의 자동화가 필요합니다. 현재는 수동으로 만들어야 합니다. 아래의 GraphQL mutation으로 만들 수 있습니다.

    참고

    <your-datahub-url>/api/graphiql에 접속해 이러한 mutation을 실행할 수 있습니다.

    mutation UpsertLogicalModelsPropagationAutomation {
  upsertActionPipeline(
    urn: "urn:li:dataHubAction:logical-models"
    input: {
      name: "Logical Models"
      category: "System"
      type: "datahub_integrations.propagation.propagation_v2.propagation_v2_action.PropagationV2Action"
      description: "Propagation metadata from logical parents to their children"
      config: {
        recipe: """
        {
          "name": "logical models",
          "action": {
            "type": "datahub_integrations.propagation.propagation_v2.propagation_v2_action.PropagationV2Action",
            "config": {
              "enabled": true,
              "propagation_rule": {
                "metadata_propagated": {
                  "tags": {},
                  "terms": {},
                  "documentation": {},
                  "ownership": {},
                  "structured_properties": {},
                  "domains": {}
                },
                "target_urn_resolution": [
                  {
                    "lookup_type": "relationship",
                    "relationship_type": "PhysicalInstanceOf"
                  }
                ]
              }
            }
          }
        }
        """
        executorId: "default"
      }
    }
  )
}
