    다국어 지원

    기능 제공 범위: DataHub Core, DataHub Cloud

    DataHub UI는 여러 언어로 표시할 수 있습니다. 다국어 지원이 활성화되면 각 사용자에게 브라우저에 맞는 언어가 자동으로 적용되며, 개인 설정에서 다른 언어로 전환할 수 있습니다. 같은 인스턴스의 사용자가 각자 가장 편한 언어로 DataHub를 사용할 수 있습니다.

    사용 가능한 언어

    • 영어(기본값)
    • 독일어(Deutsch)
    • 스페인어(Español) — 베타
    • 포르투갈어, 브라질(Português) — 베타
    • 프랑스어(Français) — 베타
    • 이탈리아어(Italiano) — 베타
    • 노르웨이어(Norsk bokmål) — 베타
    • 스웨덴어(Svenska) — 베타
    • 핀란드어(Suomi) — 베타
    • 헝가리어(Magyar) — 베타
    • 일본어(日本語) — 베타
    • 러시아어(Русский) — 베타
    • 중국어 간체(简体中文)
    • 중국어 번체(繁體中文) — 베타

    베타로 표시된 언어는 아직 다듬는 중이며 번역되지 않은 문자열이 있을 수 있습니다.

    번역 범위

    번역은 탐색, 버튼, 레이블, 대화상자, 빈 상태, 설정 페이지 등 DataHub 자체 인터페이스를 대상으로 합니다. 날짜와 시간은 선택한 언어를 따르며, 수집 일정은 해당 언어로 사람이 읽기 쉬운 설명으로 표시됩니다 (예: "Every day at 9:00 AM"은 선택한 언어의 해당 표현으로 표시됩니다). 문서 편집기의 메뉴도 번역됩니다.

    다음은 원래 언어로 유지됩니다.

    • 메타데이터. 자산 이름, 설명, 태그, 용어집 용어, 도메인, 컬럼 이름, 플랫폼 이름은 입력되거나 수집된 그대로 저장되므로 변경 없이 표시됩니다.
    • 서버 메시지. DataHub 서버가 반환하는 오류와 기타 메시지는 영어입니다.
    • 이 문서 사이트. docs.datahub.com은 영어로만 제공됩니다.

    아직 번역이 없는 문자열은 자리 표시자를 보여 주는 대신 영어로 대체됩니다. 그래서 베타 언어에서는 두 언어가 섞여 보이는 경우가 많습니다. 브라우저 로캘은 지원되는 가장 가까운 언어로 매칭되므로 de-AT는 독일어, pt-PT는 포르투갈어(브라질), zh-HK는 중국어 번체를 사용합니다.

    다국어 지원을 끄면 언어 선택기가 숨겨지고, 브라우저 로캘이나 이전에 저장한 기본 설정과 관계없이 모두에게 영어가 표시됩니다.

    언어 선택 방식

    별도로 켤 것은 없습니다. 다국어 지원은 기본적으로 활성화되어 있으며 사용자가 활성화할 필요가 없습니다. 첫 방문 시 DataHub가 브라우저 로캘에서 각 사용자의 언어를 선택하고, 일치하는 번역이 없으면 영어로 대체합니다. 다른 언어를 원하는 사용자는 Settings → Preferences에서 변경할 수 있습니다. 이 선택은 프로필에 저장되며 이후 모든 방문에서 브라우저 감지보다 우선합니다.

    인스턴스 전체에서 다국어 지원을 끄려면 GMS에서 I18N_ENABLED 환경 변수를 false로 설정하고 재시작합니다.

    새 언어 기여하기

    DataHub는 오픈소스이며, 새 언어와 기존 번역 개선에 대한 커뮤니티 기여를 환영합니다. 필요한 언어가 위 목록에 없거나 더 나은 번역을 발견하면 추가하거나 업데이트해 pull request를 열 수 있습니다.

    번역 파일은 DataHub 리포지토리의 datahub-web-react/src/i18n/locales/<language>/ 아래에 있습니다. 시작하려면 기여 가이드를 참고하고, 새 언어를 함께 조율하고 싶다면 Slack으로 문의하세요.
