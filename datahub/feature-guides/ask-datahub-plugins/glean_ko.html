    Glean 플러그인

    기능 제공 범위: DataHub Cloud 전용

    참고: Ask DataHub Plugins는 현재 비공개 베타(Private Beta)입니다. 이 기능을 활성화하려면 DataHub 고객 지원 담당자에게 문의하세요.

    Glean Plugin은 Ask DataHub를 조직의 Glean 인스턴스에 연결해 데이터 대화에서 엔터프라이즈 지식 검색을 사용할 수 있게 합니다.

    Glean을 연결하는 이유

    Glean 플러그인을 활성화하면 Ask DataHub로 다음을 할 수 있습니다.

    • 조직 지식 검색 — Glean이 인덱싱한 관련 문서, 위키, Slack 스레드 등의 콘텐츠를 찾습니다
    • 컨텍스트로 메타데이터 보완 — 데이터 카탈로그 지식과 조직 문서가 모두 필요한 질문에 답합니다
    • 격차 해소 — 데이터 생태계와 여러 도구에 저장된 팀의 암묵지를 연결합니다

    프롬프트 예시:

    • "데이터 보존 정책에 관한 내부 문서를 찾아 주세요"
    • "revenue 파이프라인과 관련된 런북을 검색해 주세요"
    • "위키에서 고객 세분화 방법론을 어떻게 설명하고 있나요?"
    • "최근 데이터 마이그레이션에 관한 Slack 논의를 찾아 주세요"

    사전 요구 사항

    • MCP 서버가 활성화된 Glean 계정(Glean MCP 문서 참고)
    • Ask DataHub Plugins가 활성화된 DataHub Cloud
    • 플러그인을 구성할 수 있는 DataHub 플랫폼 관리자 권한

    관리자 설정

    Glean 플러그인은 설정이 가장 간단합니다. DataHub는 Glean에 대해 OAuth 탐색과 자동 클라이언트 등록을 지원합니다. 즉, DataHub가 OAuth 엔드포인트와 사용 가능한 스코프를 자동으로 찾고 사용자를 대신해 클라이언트를 등록합니다. OAuth를 수동으로 구성할 필요가 없습니다.

    1단계: Glean MCP 서버 URL 가져오기

    Glean 인스턴스에서 MCP 서버 URL을 가져옵니다. Glean 설정의 MCP Configurator(프로필 설정에서 접근)에서 찾거나 Glean MCP 설정 가이드를 참고하세요.

    2단계: DataHub에서 플러그인 만들기

    1. DataHub에서 Settings > AI > Plugins로 이동합니다
    2. + Create를 클릭하고 Custom MCP를 선택합니다
    3. 플러그인 세부 정보를 입력합니다
    필드 값
    Name Glean
    Description 플러그인 설명
    MCP Server URL Glean MCP 서버 URL
    Authentication Type User OAuth (Each user authenticates)

    1. DataHub가 Glean에서 OAuth 구성을 자동으로 찾고 클라이언트를 등록하므로 OAuth를 수동으로 설정할 필요가 없습니다. 다음이 포함됩니다.

      • 승인 및 토큰 엔드포인트
      • 사용 가능한 스코프
      • 클라이언트 등록

    2. 찾아낸 스코프를 검토합니다. 기본적으로 모든 스코프가 선택되어 있습니다. mcp 스코프가 선택되어 있는지 확인하세요. 플러그인이 동작하려면 이 스코프가 필요합니다.

    경고: 필수 스코프

    Glean 플러그인이 동작하려면 mcp 스코프를 반드시 선택해야 합니다. 이 스코프가 없으면 Ask DataHub가 플러그인을 사용하려 할 때 MCP 서버가 401 Unauthorized 오류를 반환합니다. 설정 후 이 오류가 표시되면 플러그인을 편집해 mcp 스코프가 활성화되어 있는지 확인하세요.

    1. 필요하면 Instructions for the AI Assistant를 추가하고, Enable for Ask DataHub가 켜져 있는지 확인한 뒤 Create를 클릭합니다

    사용자 설정

    Settings > My AI Settings로 이동해 Glean 플러그인을 찾고 Connect를 클릭합니다. Glean으로 리디렉션되어 인증한 뒤 DataHub로 돌아옵니다. 자세한 내용은 개요를 참고하세요.

    사용 팁

    • Glean 플러그인은 DataHub의 Context Documents를 보완합니다. 큐레이션되고 거버넌스를 적용할 수 있는 지식에는 Context Documents를, 더 넓은 조직 검색에는 Glean을 사용하세요
    • AI가 질문에 따라 Glean과 DataHub 내장 검색 중 무엇을 사용할지 자동으로 결정합니다
    • 프롬프트에 찾고 있는 문서의 종류를 구체적으로 작성하세요

    문제 해결

    401 Unauthorized 오류

    OAuth succeeded but MCP server returned 401: Client error '401 Unauthorized'가 표시되면 플러그인에 mcp 스코프가 선택되지 않은 것입니다. Settings > AI > Plugins에서 플러그인을 편집해 mcp 스코프를 활성화하고 저장하세요.

    OAuth 탐색 실패

    • Glean MCP 서버 URL이 올바르고 접근 가능한지 확인합니다
    • Glean 인스턴스가 OAuth 탐색과 동적 클라이언트 등록을 지원하는지 확인합니다
    • Glean 관리자에게 문의해 MCP 서버 접근이 활성화되어 있는지 확인합니다

    결과 없음

    • Glean이 예상한 콘텐츠 소스를 인덱싱했는지 확인합니다
    • 더 넓은 검색어를 사용해 봅니다
    • 인증된 사용자가 Glean에서 관련 콘텐츠에 접근할 수 있는지 확인합니다
