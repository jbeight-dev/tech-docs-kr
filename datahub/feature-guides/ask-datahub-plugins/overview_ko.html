    Ask DataHub Plugins

    기능 제공 범위: DataHub Cloud 전용

    참고: Ask DataHub Plugins는 현재 비공개 베타(Private Beta)입니다. 이 기능을 활성화하려면 DataHub 고객 지원 담당자에게 문의하세요.

    Ask DataHub Plugins를 사용하면 Snowflake, Databricks, BigQuery, dbt Cloud, GitHub, Glean 등의 외부 도구를 Model Context Protocol(MCP)을 통해 Ask DataHub에 직접 연결할 수 있습니다.

    플러그인으로 Streamable HTTP transport를 지원하는 모든 MCP 호환 서버를 연결할 수 있습니다. 연결하면 Ask DataHub가 메타데이터 카탈로그와 함께 이러한 도구를 사용해 더 풍부한 질문에 답하고 여러 도구에 걸친 워크플로를 수행할 수 있습니다.

    플러그인을 사용하는 이유

    플러그인은 메타데이터만으로는 제공할 수 없는 강력한 기능을 제공합니다.

    • 대화형 분석: DataHub에서 적합한 데이터를 찾은 다음 Snowflake, Databricks, BigQuery에서 직접 쿼리합니다. 이 모든 과정이 하나의 대화에서 이루어집니다. DataHub는 시맨틱 계층 역할을 하며, 쿼리를 실행하기 전에 AI를 적합한 테이블로 안내합니다.
    • 도구 간 디버깅: 채팅을 떠나지 않고 dbt 실행 기록을 확인하고, Snowflake에서 테이블을 쿼리하고, GitHub에서 최근 코드 변경을 검토해 데이터 문제의 근본 원인을 찾습니다.
    • 거버넌스 워크플로: DataHub에서 데이터 리니지를 확인하고, dbt에서 변환 로직을 확인하고, 접근 제어를 검토해 여러 시스템의 컨텍스트를 한데 모읍니다.

    사용 가능한 플러그인

    DataHub는 널리 쓰이는 도구를 위한 내장 플러그인 템플릿을 제공합니다. 내부 서비스, 커스텀 API, MCP 서버가 있는 도구 등 다른 MCP 서버에 연결하려면 Custom MCP 옵션을 사용하세요.

    플러그인 설명 가이드
    Snowflake Snowflake 데이터를 쿼리하고 탐색합니다 설정 가이드
    Databricks Databricks 데이터를 쿼리하고 탐색합니다 설정 가이드
    BigQuery BigQuery 데이터를 쿼리하고 탐색합니다 설정 가이드
    dbt Cloud 작업 실행, 모델 정의, 테스트 결과를 확인합니다 설정 가이드
    GitHub 리포지토리를 탐색하고, PR을 올리고, 이슈를 관리합니다 설정 가이드
    Glean 조직의 지식 베이스를 검색합니다 설정 가이드
    Custom MCP 모든 MCP 호환 서버를 연결합니다 아래 참고

    동작 방식

    플러그인은 두 단계 워크플로를 따릅니다.

    1. 관리자가 구성: Settings > AI > Plugins에서 MCP 서버에 연결해 플러그인을 구성합니다
    2. 사용자가 활성화: 개인 설정(Settings > My AI Settings)이나 채팅 인터페이스에서 사용할 플러그인을 활성화합니다

    사용자가 플러그인을 활성화하면 Ask DataHub 대화 중에 해당 도구를 사용할 수 있습니다. AI 어시스턴트는 질문과 관련이 있을 때 이러한 도구를 자동으로 사용합니다.

    관리자 설정: 플러그인 구성

    정보: 필요한 권한

    플러그인을 구성하려면 Manage Platform Settings 권한이 있어야 합니다.

    플러그인 만들기

    1. Settings > AI > Plugins로 이동합니다
    2. 오른쪽 상단의 + Create를 클릭합니다
    3. 내장 플러그인 템플릿(Snowflake, dbt Cloud, GitHub)을 선택하거나, 다른 도구의 경우 Custom MCP를 선택합니다

    Custom MCP 플러그인 구성

    Custom MCP를 사용하면 Notion이나 Glean 같은 서드파티 도구, 팀에서 구축한 내부 서비스, MCP로 노출된 기타 API 등 모든 MCP 호환 서버를 연결할 수 있습니다. 서버는 Streamable HTTP transport를 지원해야 합니다.

    Custom MCP 플러그인을 만들 때 다음을 입력합니다.

    필드 설명
    Name 플러그인의 표시 이름(모든 사용자에게 표시)
    Description 이 플러그인이 제공하는 기능에 대한 간단한 설명
    MCP Server URL 원격 MCP 서버의 URL
    Authentication Type 사용자가 MCP 서버에 인증하는 방식(아래 참고)
    Instructions for the AI Assistant 이 플러그인을 사용할 때 Ask DataHub에 제공하는 커스텀 지침(선택 사항)

    인증 유형

    플러그인은 세 가지 인증 메커니즘을 지원합니다.

    None(공개 API)

    인증이 필요하지 않습니다. 자격 증명이 필요 없는 공개 MCP 서버에 사용합니다.

    Shared API Key(시스템 전체)

    모든 사용자가 하나의 API 키를 공유합니다. 관리자가 설정 중에 키를 입력하며, 이 키가 모든 사용자의 요청에 사용됩니다. 단일 서비스 계정이 적합한 도구에 가장 알맞습니다.

    User API Key(사용자별 개별 입력)

    각 사용자가 플러그인을 활성화할 때 자신의 API 키를 입력합니다. 이를 통해 사용자별 접근 제어와 감사 추적을 보장합니다. 플러그인에 연결할 때 키를 입력하라는 메시지가 표시됩니다.

    User OAuth(사용자별 인증)

    각 사용자가 플러그인을 활성화할 때 OAuth로 인증합니다. 관리자가 OAuth 제공자(client ID, client secret, authorization URL, token URL, 스코프)를 구성하면, 사용자는 표준 OAuth 로그인 흐름을 거쳐 연결합니다.

    연결 테스트

    플러그인을 구성한 뒤 저장하기 전에 Test Connection을 클릭해 MCP 서버에 연결할 수 있는지와 자격 증명이 유효한지 확인합니다.

    커스텀 지침

    Instructions for the AI Assistant 필드에서 Ask DataHub가 플러그인을 사용하는 방법에 대한 지침을 제공할 수 있습니다. 예를 들면 다음과 같습니다.

    • "사용자가 매출이나 고객 메트릭에 관해 물으면 이 플러그인으로 Snowflake를 쿼리하세요."
    • "데이터 품질을 보고하기 전에 항상 dbt 테스트 결과를 확인하세요."

    이 지침은 플러그인이 활성화될 때마다 AI 컨텍스트에 주입됩니다.

    사용자 설정: 플러그인 활성화

    관리자가 플러그인을 구성하면 모든 사용자가 자신의 Ask DataHub 환경에서 활성화할 수 있습니다.

    개인 설정에서 활성화

    1. Settings > My AI Settings로 이동합니다
    2. 관리자가 구성한 사용 가능한 모든 플러그인 목록이 표시됩니다
    3. 플러그인을 켜서 활성화하거나, Connect를 클릭해 인증합니다(API Key 또는 OAuth 플러그인의 경우)

    채팅 인터페이스에서 활성화

    Ask DataHub 채팅에서 플러그인을 직접 관리할 수도 있습니다.

    1. 채팅 입력란 옆의 플러그인 아이콘을 클릭합니다
    2. 드롭다운에 사용 가능한 모든 플러그인과 연결 상태가 표시됩니다
    3. 플러그인을 켜거나 끄고, Manage AI plugins를 클릭해 인증을 구성합니다

    인증이 필요한 플러그인의 경우 자격 증명을 입력하라는 메시지가 표시됩니다.

    대화에서 플러그인 사용하기

    활성화하면 Ask DataHub 대화 중에 플러그인 도구를 매끄럽게 사용할 수 있습니다. 질문만 하면 AI 어시스턴트가 적절한 도구를 자동으로 사용합니다.

    워크플로 예시:

    • "이번 달 Snowflake에서 가장 많이 쿼리된 테이블은 무엇인가요?" — DataHub 검색 + Snowflake 쿼리
    • "revenue 모델의 최근 dbt 실행이 성공했나요?" — dbt Cloud 작업 기록
    • "ETL 파이프라인 코드의 최근 변경 사항을 보여 주세요" — GitHub 커밋 탐색
    • "데이터 보존 정책에 관한 내부 문서를 찾아 주세요" — Glean 지식 검색
