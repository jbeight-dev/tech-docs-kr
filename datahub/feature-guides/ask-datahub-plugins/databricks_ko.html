    Databricks 플러그인

    기능 제공 범위: DataHub Cloud 전용

    참고: Ask DataHub Plugins는 현재 비공개 베타(Private Beta)입니다. 이 기능을 활성화하려면 DataHub 고객 지원 담당자에게 문의하세요.

    Databricks Plugin은 Databricks MCP 서버를 통해 Ask DataHub를 Databricks 워크스페이스에 연결해 채팅에서 바로 대화형 분석을 할 수 있게 합니다. Snowflake 플러그인과 마찬가지로 DataHub는 적합한 데이터를 찾는 시맨틱 계층 역할을 하고, Databricks는 쿼리를 실행해 결과를 반환하는 데이터 계층 역할을 합니다.

    Databricks를 연결하는 이유

    Databricks 플러그인을 활성화하면 Ask DataHub로 다음을 할 수 있습니다.

    • 대화형 분석 — 일상적인 언어로 질문하고 실제 데이터에 근거한 답변을 받습니다. DataHub가 메타데이터로 적합한 테이블을 찾으면 Databricks가 SQL 쿼리를 실행합니다.
    • 데이터 탐색 — Unity Catalog 전반에서 데이터셋 구조를 이해하고, 샘플 데이터를 미리 보고, 컬럼 값을 살펴봅니다.
    • 데이터 디버깅 — DataHub assertion이 감지한 데이터 문제를 소스의 실제 데이터를 쿼리해 조사합니다.

    플러그인이 OAuth를 사용하므로 각 사용자는 자신의 Databricks 계정으로 인증합니다. 사용자는 접근 권한을 부여받은 데이터만 볼 수 있습니다.

    프롬프트 예시:

    • "생애 가치 기준 상위 10개 고객을 쿼리해 주세요"
    • "오늘 events 테이블에 몇 개의 행이 추가되었나요?"
    • "orders 테이블의 샘플 행 5개를 보여 주세요"
    • "users 테이블의 email 컬럼에 null 값이 있는지 확인해 주세요"

    사전 요구 사항

    • Managed MCP Servers가 활성화된 Databricks 워크스페이스
    • Databricks에서 OAuth 앱 연결을 만들 수 있는 관리자 권한(Settings > App connections)
    • Ask DataHub Plugins가 활성화된 DataHub Cloud
    • 플러그인을 구성할 수 있는 DataHub 플랫폼 관리자 권한

    관리자 설정

    Databricks 플러그인은 User OAuth 인증을 사용하며, 각 사용자가 자신의 Databricks 계정으로 인증합니다. 설정 과정은 Databricks에서 OAuth 앱 연결을 만든 다음 DataHub에서 플러그인을 구성하는 순서입니다.

    1단계: Databricks에서 OAuth 앱 연결 만들기

    1. Databricks에서 Settings > App connections로 이동합니다
    2. Add connection을 클릭하고 세부 정보를 입력합니다
    필드 값
    Application Name DataHub(또는 식별하기 쉬운 이름)
    Redirect URLs https://<your-datahub-url>/integrations/oauth/callback
    Access scopes SQL 선택
    Generate a client secret 선택

    주의: 리디렉션 URL

    Redirect URL은 DataHub 플러그인 생성 양식에 표시된 OAuth Callback URL과 정확히 일치해야 합니다(예: https://your-org.acryl.io/integrations/oauth/callback). 3단계에서 플러그인을 만들 때 DataHub 양식에서 이 URL을 복사할 수 있습니다.

    1. Add를 클릭합니다

    2단계: 자격 증명 수집

    연결을 만들면 대화상자에 Client ID와 Client Secret이 표시됩니다. 둘 다 바로 복사하세요. client secret은 다시 표시되지 않습니다.

    3단계: DataHub에서 플러그인 만들기

    1. DataHub에서 Settings > AI > Plugins로 이동합니다
    2. + Create를 클릭하고 Custom MCP를 선택합니다
    3. 플러그인 세부 정보를 입력합니다
    필드 값
    Name Databricks
    Description 플러그인 설명
    MCP Server URL https://<your-workspace-hostname>/api/2.0/mcp/sql
    Authentication Type User OAuth (Each user authenticates)
    1. DataHub가 Databricks에서 authorization URL, token URL, 사용 가능한 스코프를 포함한 OAuth 구성을 자동으로 찾습니다. 다음을 입력합니다
    필드 값
    Client ID 2단계에서 얻은 값
    Client Secret 2단계에서 얻은 값
    Default Scopes sql(최소 필수)

    정보: 액세스 스코프

    sql 스코프는 Ask DataHub가 쿼리를 실행하는 데 필요한 최소 스코프입니다. Databricks 앱 연결을 만들 때 All APIs를 선택했다면 추가 스코프를 사용할 수 있으며, 필요한 스코프만 선택하세요.

    1. 필요하면 Instructions for the AI Assistant를 추가하고, Enable for Ask DataHub가 켜져 있는지 확인한 뒤 Create를 클릭합니다

    사용자 설정

    Settings > My AI Settings로 이동해 Databricks 플러그인을 찾고 Connect를 클릭합니다. Databricks로 리디렉션되어 인증한 뒤 DataHub로 돌아옵니다. 자세한 내용은 개요를 참고하세요.

    문제 해결

    OAuth 실패

    • Databricks의 Redirect URL이 DataHub에 표시된 OAuth Callback URL과 정확히 일치하는지 확인합니다
    • Client ID와 Client Secret을 올바르게 입력했는지 확인합니다
    • 워크스페이스에 IP 접근 제한이 있다면 DataHub의 아웃바운드 IP가 허용 목록에 있는지 확인합니다

    쿼리 실패

    • 사용자가 쿼리하는 Unity Catalog 테이블에 접근 권한이 있는지 확인합니다
    • Databricks에서 앱 연결을 만들 때 sql 스코프를 선택했는지 확인합니다
    • 워크스페이스에 사용 가능한 SQL warehouse가 실행 중인지 확인합니다
