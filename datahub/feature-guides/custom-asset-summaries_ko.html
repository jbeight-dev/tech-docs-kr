    Asset Summaries

    기능 제공 범위: DataHub Cloud 전용

    DataHub의 Asset Summaries를 사용하면 사용자가 Domains, Data Products, Glossary Terms, Glossary Term Groups, Datasets를 탐색할 때 보는 Summary 탭을 사용자 지정해, 가장 중요한 자산에 맞춘 큐레이션된 탐색 환경을 만들 수 있습니다.

    정보: 지원되는 자산 유형

    Asset Summaries는 현재 다음을 지원합니다.

    • 논리 자산: Domains, Data Products, Glossary Terms, Glossary Term Groups. DataHub 내에서 물리 데이터 자산을 구성하고 묶는 데 도움이 됩니다
    • 물리 자산: Datasets. 실제 데이터 테이블과 컬렉션을 종합적으로 보여 줍니다

    Asset Summaries를 사용하는 이유

    Asset Summaries는 팀이 조직의 핵심 자산을 찾고 탐색하는 방식을 다음과 같이 바꿉니다.

    • 자산 검색 가능성 향상: 도메인, 데이터 제품, 용어집 용어에 관한 가장 관련성 높은 정보를 Summary 탭에서 바로 강조합니다
    • 소유자 주도 환경 구성: 자산 소유자가 사용자에게 가장 중요한 정보를 큐레이션할 수 있습니다
    • 탐색 시간 단축: 사용자가 여러 탭을 클릭하지 않아도 핵심 세부 정보, 문서, 관련 자산을 보여 줍니다
    • 자산 표현 표준화: 가장 중요한 조직 구성 요소를 일관되고 전문적으로 표현합니다

    핵심 데이터 제품을 강조하려는 도메인 소유자, 중요한 자산을 소개하는 데이터 제품 관리자, 용어집 용어를 정리하는 데이터 스튜어드, 데이터셋 세부 정보를 제시하는 데이터 소유자 모두, Asset Summaries로 가장 관련성 높은 정보를 전면에 내세울 수 있습니다.

    포함된 항목

    Asset Summaries는 자산의 고유한 요구에 맞게 조정할 수 있는 세 가지 사용자 지정 섹션으로 구성됩니다.

    Summary 페이지 헤더

    헤더 섹션은 자산의 핵심 속성을 바로 볼 수 있도록 보여 줍니다. 기본적으로 다음을 포함합니다.

    • 소유권 정보 - 이 자산의 소유자와 관리자
    • 생성 날짜 - 자산이 만들어진 시점
    • 태그 - 자산 분류(태그를 지원하는 자산에서 사용 가능)
    • 용어집 용어 - 자산에 적용된 비즈니스 컨텍스트와 정의
    • 도메인 연결 - 조직 내 위치
    • 구조화된 속성 - 강조하려는 커스텀 메타데이터 필드

    기본 속성을 제거하거나 새 속성을 추가해 사용자와 가장 관련 있는 속성을 표시하도록 이 섹션을 사용자 지정할 수 있습니다. 속성 사용 가능 여부는 자산 유형의 지원 범위에 따라 다릅니다. 예를 들어 현재 모든 논리 자산 유형이 태그를 지원하지는 않습니다.

    문서 및 링크 섹션

    이 섹션은 쉽게 접근할 수 있도록 Summary 탭에서 바로 문서 기능을 제공합니다.

    • 서식 있는 텍스트 문서 - 자산에 대한 자세한 설명을 추가, 편집, 서식 지정합니다
    • 리소스 링크 - 외부 문서, 대시보드, 도구 등 관련 리소스의 링크를 포함합니다
    • 빠른 접근 - 사용자가 별도의 Documentation 탭으로 이동하지 않아도 됩니다

    모듈 섹션

    모듈 섹션은 기본 모듈과 커스텀 모듈을 통해 자산의 맥락 정보와 탐색 기능을 제공합니다.

    기본 모듈

    각 자산 유형에는 관련 기본 모듈이 포함됩니다.

    • Assets Module(Domains, Data Products, Glossary Terms): 이 도메인이나 데이터 제품에 속하거나 이 용어집 용어로 태그된 데이터 자산을 보여 줍니다
    • Domains Module(Domains만 해당): 이 도메인 내 하위 도메인의 계층 구조를 표시합니다
    • Data Products Module(Domains만 해당): 이 도메인에 포함된 모든 데이터 제품을 나열합니다
    • Contents Module(Glossary Term Groups만 해당): 계층을 쉽게 탐색할 수 있도록 하위 용어집 용어와 용어 그룹을 보여 줍니다
    • Related Terms Module(Glossary Terms만 해당): 현재 용어와 관계를 공유하는 모든 용어를 나열합니다
    • Lineage Module(Datasets만 해당): 데이터셋의 리니지 그래프를 미리 보여 주며 업스트림과 다운스트림 의존성을 표시합니다
    • Columns Module(Datasets만 해당): 데이터셋의 컬럼 스키마를 테이블 형식으로 표시해, Schema 탭으로 이동하지 않고도 컬럼 세부 정보를 빠르게 볼 수 있습니다

    커스텀 모듈

    홈 페이지에서 사용할 수 있는 커스텀 모듈도 추가할 수 있습니다.

    • Collection: 강조하려는 특정 자산을 큐레이션한 목록
    • Documentation: 사용자가 봐야 할 중요한 문서 고정
    • Hierarchy: 도메인 또는 용어집 용어별로 구성한 자산의 하향식 뷰

    Asset Summaries 활성화

    Asset Summaries는 GMS(Generalized Metadata Service) 컨테이너에 설정해야 하는 기능 플래그로 제어됩니다.

    • ASSET_SUMMARY_PAGE_V1: Domains, Data Products, Glossary Terms, Glossary Term Groups의 Asset Summaries를 제어합니다
    • DATASET_SUMMARY_PAGE_V1: Datasets의 Asset Summaries를 제어합니다

    DataHub 인스턴스에서 Asset Summaries를 활성화하려면 GMS 컨테이너에서 해당 환경 변수를 true로 설정합니다.

    # For logical assets (Domains, Data Products, Glossary Terms, Glossary Term Groups)
ASSET_SUMMARY_PAGE_V1=true

# For physical assets (Datasets)
DATASET_SUMMARY_PAGE_V1=true

    요약 페이지를 제공할 자산 유형에 따라 기능 플래그를 하나 또는 둘 다 활성화할 수 있습니다.

    Asset Summaries 사용자 지정

    참고

    사용자 지정은 현재 DataHub Cloud에서만 지원합니다. DataHub Core는 사용자 지정할 수 없는 기본 요약 페이지를 지원합니다.

    Summary 페이지 헤더 편집

    자산 헤더에 표시되는 속성을 사용자 지정하는 방법은 다음과 같습니다.

    1. 자산의 Summary 탭으로 이동합니다
    2. 헤더 섹션의 더하기 아이콘을 클릭해 새 속성을 추가합니다
    3. 기존 속성의 이름을 클릭해 교체하거나 제거합니다

    문서 및 링크 관리

    Summary 탭에서 문서와 링크를 바로 추가하거나 업데이트합니다.

    1. "About" 섹션 헤더 오른쪽의 "Edit Description" 아이콘을 클릭합니다
    2. 서식 있는 텍스트 편집기로 내용의 서식을 지정합니다
    3. "About" 섹션 헤더 오른쪽의 "Add Link" 아이콘을 클릭합니다
    4. 링크가 나열된 곳에서 필요에 따라 편집하거나 제거해 정리합니다

    모듈 추가 및 배치

    가장 중요한 정보를 강조하도록 모듈 섹션을 사용자 지정합니다.

    1. 기존 모듈 아래의 "plus" 버튼을 클릭해 사용 가능한 모듈 유형을 찾습니다
    2. 모듈을 끌어다 놓아 순서를 변경합니다
    3. 모듈 메뉴의 편집 또는 제거 옵션으로 기존 모듈을 수정합니다

    참고: 전역 변경

    자산의 Summary 페이지에 적용한 변경 사항은 해당 자산을 보는 모든 사용자에게 표시됩니다. 사용자 지정 내용은 해당 도메인, 데이터 제품, 용어집 용어, 데이터셋에 접근하는 모든 사람의 기본 환경이 됩니다.

    권한과 접근 제어

    Asset Summaries를 사용자 지정하려면 편집할 특정 자산에 대한 "Manage Asset Summary" 권한이 필요합니다. 이 권한은 다른 접근 제어와 함께 DataHub 정책 편집기에서 구성할 수 있습니다. 기본적으로 Admins, Editors, 자산 소유자에게 이 권한이 부여됩니다.

    참고: API 동등성

    UI와 GraphQL updateAssetSettings mutation은 자산에 대한 Manage Asset Summary 또는 Edit Entity를 허용합니다. OpenAPI나 Rest.li로 assetSettings aspect를 직접 쓰는 작업은 일반 엔터티 업데이트로 권한을 확인하므로 Edit Entity가 필요하며, 이러한 API에서는 Manage Asset Summary만으로는 충분하지 않습니다.

    권한 설정

    1. Settings > Permissions > Policies로 이동합니다
    2. "Manage Asset Summary" 권한을 포함하도록 정책을 만들거나 편집합니다
    3. 적절한 사용자 또는 그룹에 정책을 할당합니다
    4. 특정 자산이나 자산 유형에 정책을 적용합니다

    이 세분화된 권한 시스템은 권한이 있는 사용자만 조직의 핵심 자산이 팀 전체에 표시되는 방식을 수정할 수 있도록 보장합니다.

    모범 사례

    Asset Summaries를 사용자 지정할 때는 다음을 따르세요.

    • 사용자 요구에 집중: 사용자가 자산을 효과적으로 이해하고 탐색하는 데 도움이 되는 속성과 모듈을 포함합니다
    • 관련성 유지: Summary 페이지를 과도하게 채우지 말고 가장 중요한 정보를 우선합니다
    • 정기적으로 업데이트: 자산과 조직의 변화에 맞춰 사용자 지정 내용을 검토하고 새로 고칩니다
    • 대상 고려: 팀이 이러한 자산을 일반적으로 사용하는 방식에 맞게 구성합니다
    • 모듈을 전략적으로 활용: 기본 모듈로 관계를 보여 주고, 커스텀 모듈로 특정 컬렉션이나 문서를 강조합니다

    다음 단계

    Asset Summaries를 이해했으니 이제 다음을 진행합니다.

    1. 기능 활성화: GMS 컨테이너에 적절한 기능 플래그(ASSET_SUMMARY_PAGE_V1 또는 DATASET_SUMMARY_PAGE_V1, 또는 둘 다)를 설정합니다
    2. 트래픽이 많은 자산부터 시작: 가장 자주 접근하는 도메인, 데이터 제품, 데이터셋의 Summary 페이지부터 사용자 지정합니다
    3. 데이터셋 전용 모듈 활용: 데이터셋에는 Lineage와 Columns 모듈을 활용해 데이터 의존성과 스키마를 바로 볼 수 있게 합니다
    4. 피드백 수집: Summary 페이지에서 어떤 정보가 가장 도움이 될지 사용자에게 묻습니다
    5. 사용 현황에 따라 반복 개선: 사용자가 사용자 지정된 요약과 상호작용하는 방식을 모니터링하고 그에 맞게 조정합니다
    6. 신중하게 확장: 초기 사용자 지정에서 얻은 교훈을 조직의 다른 자산에 적용합니다

    Asset Summaries는 조직의 요구에 맞춰 발전하도록 설계되었으며, DataHub의 강점인 구조를 유지하면서 사용자에게 실제로 도움이 되는 탐색 환경을 유연하게 만들 수 있습니다.
