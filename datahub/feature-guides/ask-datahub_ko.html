    Ask DataHub

    기능 제공 범위: DataHub Cloud 전용

    Ask DataHub는 작업하는 곳에서 바로 컨텍스트를 이해하는 지능형 도움을 제공하는 DataHub의 대화형 AI 어시스턴트입니다. Ask DataHub에 조직의 데이터에 관해 질문하면 메타데이터 그래프와 Context Graph에 저장된 런북, 정책, FAQ 같은 조직 지식을 바탕으로 정확한 답변을 즉시 받을 수 있습니다.

    Ask DataHub로 할 수 있는 일

    Ask DataHub를 사용하면 조직 전체 데이터 생태계를 쉽게 탐색하고 이해할 수 있습니다. 기술 메타데이터와 팀의 암묵지를 결합해 더 똑똑하고 신뢰할 수 있는 답변을 제공합니다.

    신뢰할 수 있는 데이터 찾기

    사용 패턴, 문서화 품질, 소유권 정보, 데이터 품질 메트릭을 바탕으로 고품질의 신뢰할 수 있는 데이터 자산을 찾습니다. Ask DataHub는 분석에 가장 권위 있는 소스를 식별하도록 돕습니다.

    영향 분석 수행

    데이터 자산 변경이 조직 전체에 어떤 영향을 미칠지 빠르게 평가합니다. Ask DataHub는 리니지를 추적해 모든 다운스트림 의존성을 식별하므로, 변경 전에 정보에 근거해 결정할 수 있습니다.

    더 깊이 살펴보기

    데이터 생태계의 누가, 무엇을, 언제, 어디서, 왜를 파악합니다.

    • 소유권: 특정 데이터 자산의 소유자를 찾습니다
    • 인기도: 어떤 데이터가 가장 인기 있고 누가 사용하는지 파악합니다
    • 기록: 과거 사용 패턴과 조직 지식을 알아봅니다

    암묵지 활용

    Ask DataHub는 조직의 Context Documents, Glossary Terms, Domains 등을 참조해 팀의 공유 지식에 근거한 일관되고 신뢰할 수 있는 답변을 제공합니다.

    • 모범 사례: 문서화된 런북과 품질 기준을 따릅니다
    • 런북, 가이드, FAQ: 데이터 접근을 요청하는 올바른 절차를 알아봅니다
    • 정책: 컴플라이언스 요구 사항과 데이터 처리 지침을 이해합니다

    팁: Ask DataHub 응답 개선하기

    자주 묻는 질문, 정책, 정의를 Context Documents에 문서화하면 Ask DataHub가 조직 전체에서 더 정확하고 일관된 답변을 제공하는 데 도움이 됩니다.

    데이터 품질 평가

    데이터 자산의 상태와 신뢰성을 빠르게 파악합니다.

    • assertion 결과와 데이터 품질 점수 확인
    • 최신성과 검증 상태 파악
    • 데이터를 사용하기 전에 잠재적 문제 식별
    • 과거 품질 추세에 대한 컨텍스트 확인

    SQL 쿼리 작성

    특정 분석 질문에 답하는 SQL 쿼리 초안을 생성해 데이터 탐색과 분석 워크플로를 가속합니다.

    Ask DataHub를 사용할 수 있는 곳

    시작하기

    DataHub UI

    Ask DataHub는 현재 공개 베타(Public Beta)로 DataHub 내 여러 위치에서 사용할 수 있습니다.

    • 왼쪽 탐색 모음의 Chat 탭: DataHub와 새 대화를 시작할 수 있습니다
    • Data Sources 구성 흐름: DataHub가 수집 소스 문제 해결을 도와줍니다
    • Asset Profile Sidebar: 특정 DataHub 자산에 관한 채팅을 시작할 수 있습니다.
    • Chrome Extension 사이드바의 Ask Tab.

    Slack

    Slack의 어느 채널에서든 @DataHub를 멘션하면 Ask DataHub를 사용할 수 있습니다. DataHub의 지능을 팀 대화에 바로 가져옵니다.

    Microsoft Teams

    마찬가지로 Microsoft Teams의 채널과 채팅에서 @DataHub를 멘션해 Ask DataHub를 사용할 수 있습니다.

    Ask DataHub 사용자 지정

    v0.3.15부터 커스텀 지침을 구성해 Ask DataHub가 쿼리에 응답하는 방식을 사용자 지정할 수 있습니다. 커스텀 지침은 AI 컨텍스트에 주입되어, 조직의 고유한 요구 사항, 용어, 지침에 맞게 AI 어시스턴트의 동작을 조정합니다.

    커스텀 지침 구성

    커스텀 지침을 구성하는 방법은 다음과 같습니다.

    1. DataHub 인스턴스에서 Settings > AI로 이동합니다
    2. Ask DataHub 섹션을 찾습니다
    3. Instructions 필드에 커스텀 지침을 입력합니다

    이것으로 끝입니다!

    커스텀 기본 프롬프트로 다음을 할 수 있습니다.

    • 응답 스타일과 어조 정의
    • 조직 고유의 용어 정의
    • 모델이 Glossary Terms, Tags, Domains, 속성을 탐색하는 방법 안내
    • 어시스턴트가 특정 추천을 하도록 안내(예: 스테이징 자산보다 프로덕션 자산을 구분해 안내)

    커스텀 지침을 변경한 뒤 Ask DataHub에 반영되기까지 최대 5분이 걸릴 수 있습니다.

    팁: Context Documents + 커스텀 지침

    조직 고유의 정의, 정책, 절차는 커스텀 지침 대신(또는 함께) Context Documents에 문서화하는 것을 고려하세요. Context Documents는 거버넌스를 적용하고 버전을 관리할 수 있으며 특정 자산에 연결할 수 있어, 조직이 변화해도 유지 관리하기 쉽습니다.

    뷰 선택

    v0.3.17부터 채팅 인터페이스에서 View를 직접 선택해, 대화에서 Ask DataHub가 검색하는 자산의 범위를 좁힐 수 있습니다. 팀이 소유한 데이터셋, 특정 도메인, 큐레이션된 데이터 제품 컬렉션처럼 데이터 생태계의 특정 부분에 집중하고 싶을 때 유용합니다.

    뷰를 선택하려면 채팅 입력란 옆의 뷰 선택 드롭다운을 클릭합니다. 개인 뷰나 조직 전체에 공유된 공개 뷰 중에서 선택할 수 있습니다.

    뷰가 활성화되면 Ask DataHub는 해당 뷰에 포함된 데이터셋, 대시보드, 데이터 제품, 도메인, 문서, 기타 자산으로 검색을 제한해 관련성 높은 답변을 더 빠르게 제공합니다. 뷰를 명시적으로 선택하지 않으면 조직의 기본 뷰(설정된 경우)가 사용됩니다.

    참고: Slack 및 Microsoft Teams

    Slack이나 Microsoft Teams에서 Ask DataHub를 사용할 때는 조직의 기본 뷰가 항상 자동으로 적용됩니다.

    동작 방식

    Ask DataHub는 전체 메타데이터 그래프와 조직 지식을 활용해 컨텍스트를 이해하는 지능형 응답을 제공합니다. AI 어시스턴트는 다음을 고려합니다.

    • 자산 이름, 설명, 문서
    • 리니지 관계(업스트림 및 다운스트림)
    • 소유권 및 도메인 정보
    • 사용 패턴과 인기도 메트릭
    • 데이터 품질과 assertion 결과
    • 태그, 용어집 용어, 분류
    • 스키마 정보와 샘플 값
    • Context Documents(게시된 런북, 정책, FAQ, 정의)

    구조화된 메타데이터와 비구조화된 조직 지식을 결합하므로, Ask DataHub는 기술적인 질문("이 테이블에 무엇이 들어 있나요?")과 맥락적인 질문("이 테이블을 어떻게 사용해야 하나요?") 모두에 팀의 공유된 이해를 바탕으로 일관되고 신뢰할 수 있는 답변을 제공합니다.
