    데이터셋 사용량 및 쿼리 기록

    기능 제공 범위: DataHub Core, DataHub Cloud

    Dataset Usage & Query History는 데이터셋을 참조한 상위 쿼리 등 데이터셋 수준의 정보를 제공합니다.

    사용량 데이터를 보면 해당 데이터셋을 가장 잘 알 만한 상위 사용자와, 이 데이터셋을 참조하는 상위 쿼리를 파악할 수 있습니다. 전체 쿼리 수와 고유 사용자 수의 개요도 확인할 수 있습니다. 일부 소스에서는 컬럼 수준 사용량도 계산하므로, 자주 사용되는 컬럼을 파악하는 데 도움이 됩니다.

    사용량 통계를 지원하는 소스에서는 데이터셋, 대시보드, 차트의 사용량을 수집할 수 있습니다.

    Dataset Usage & Query History 설정, 사전 요구 사항, 권한

    Dataset Usage & Query History 데이터를 수집하려면 먼저 해당 소스의 문서에서 DataHub 소스가 이 기능을 지원하는지와 활성화 방법을 확인해야 합니다.

    DataHub 소스 문서의 기능(capabilities) 섹션에서 확인할 수 있습니다.

    일부 소스는 Usage 및 Query History 메타데이터를 수집하기 위해 사용량 전용 recipe를 별도로 요구합니다. 이 경우 기능 요약에 다음과 같이 표시됩니다.

    소스에 사용량 사전 요구 사항 페이지가 있으면 항상 확인하시기 바랍니다. 사용량 수집에만 필요한 권한을 추가해야 할 수도 있습니다.

    Dataset Usage & Query History 사용하기

    수집에 성공하면 사용량이 있는 데이터셋에서 Queries 탭과 Stats 탭이 활성화됩니다.

    Queries 탭에서는 이 데이터셋을 참조하며 가장 자주 실행된 상위 5개 쿼리를 볼 수 있습니다.

    Stats 탭에서는 이 데이터셋을 참조하는 쿼리를 가장 많이 실행한 상위 5명의 사용자를 볼 수 있습니다.

    수집된 사용량 데이터로 컬럼 수준 사용량 통계도 볼 수 있습니다(Redshift Usage는 아직 이 기능을 지원하지 않습니다).

    FAQ 및 문제 해결

    Queries/Stats 탭이 회색으로 비활성화되어 있는 이유는 무엇인가요?

    해당 데이터셋에 사용량 통계가 없거나, 사용량 추출을 포함한 수집을 아직 실행한 적이 없으면 Queries/Stats 탭이 회색으로 비활성화됩니다.
