    Skills 찾기

    이 skill은 오픈 에이전트 skill 생태계에서 skill을 찾아 설치하도록 돕습니다.

    이 Skill을 사용하는 경우

    사용자가 다음과 같이 말하면 이 skill을 사용합니다.

    • X가 이미 skill로 나와 있을 법한 흔한 작업일 때 "X를 어떻게 하나요?"라고 묻는 경우
    • "X용 skill을 찾아 줘" 또는 "X용 skill이 있나요?"라고 말하는 경우
    • X가 전문적인 기능일 때 "X를 할 수 있나요?"라고 묻는 경우
    • 에이전트 기능을 확장하는 데 관심을 보이는 경우
    • 도구, 템플릿, 워크플로를 찾으려는 경우
    • 특정 분야(디자인, 테스트, 배포 등)에서 도움을 받고 싶다고 말하는 경우

    Skills CLI란?

    Skills CLI(npx skills)는 오픈 에이전트 skill 생태계의 패키지 관리자입니다. Skill은 전문 지식, 워크플로, 도구로 에이전트의 기능을 확장하는 모듈형 패키지입니다.

    주요 명령어:

    • npx skills find [query] [--owner <owner>] - 대화형으로 또는 키워드로 skill을 검색합니다. 특정 GitHub 소유자로 범위를 좁힐 수도 있습니다.
    • npx skills add <package> - GitHub 또는 다른 소스에서 skill을 설치합니다.
    • npx skills update - 설치된 모든 skill을 업데이트합니다.

    Skill 둘러보기: https://skills.sh/

    사용자가 Skill을 찾도록 돕는 방법

    1단계: 사용자에게 필요한 것 파악하기

    사용자가 도움을 요청하면 다음을 파악합니다.

    1. 분야(예: React, 테스트, 디자인, 배포)
    2. 구체적인 작업(예: 테스트 작성, 애니메이션 제작, PR 리뷰)
    3. skill이 있을 만큼 흔한 작업인지 여부

    2단계: 리더보드 먼저 확인하기

    CLI로 검색하기 전에 skills.sh 리더보드에서 해당 분야에 잘 알려진 skill이 이미 있는지 확인합니다. 리더보드는 총 설치 수로 skill의 순위를 매기므로, 인기 있고 충분히 검증된 skill을 쉽게 찾을 수 있습니다.

    예를 들어 웹 개발 분야의 상위 skill은 다음과 같습니다.

    • vercel-labs/agent-skills — React, Next.js, 웹 디자인(각각 100K+ 설치)
    • anthropics/skills — 프런트엔드 디자인, 문서 처리(100K+ 설치)

    3단계: Skill 검색하기

    리더보드에서 사용자에게 필요한 skill을 찾지 못하면 find 명령어를 실행합니다.

    npx skills find [query] [--owner <owner>]

    예를 들면 다음과 같습니다.

    • 사용자가 "React 앱을 더 빠르게 하려면 어떻게 해야 하나요?"라고 묻는 경우 → npx skills find react performance
    • 사용자가 "PR 리뷰를 도와줄 수 있나요?"라고 묻는 경우 → npx skills find pr review
    • 사용자가 "changelog를 만들어야 해요"라고 말하는 경우 → npx skills find changelog

    4단계: 추천하기 전에 품질 확인하기

    검색 결과만 보고 skill을 추천하면 안 됩니다. 항상 다음을 확인합니다.

    1. 설치 수 — 설치 수가 1K+인 skill을 우선합니다. 100 미만인 skill은 주의합니다.
    2. 출처 평판 — 공식 출처(vercel-labs, anthropics, microsoft)가 알려지지 않은 작성자보다 신뢰할 만합니다.
    3. GitHub 스타 — 소스 저장소를 확인합니다. 스타가 100개 미만인 저장소의 skill은 의심스럽게 봅니다.

    5단계: 사용자에게 선택지 제시하기

    관련 skill을 찾으면 다음 내용을 사용자에게 제시합니다.

    1. skill 이름과 기능
    2. 설치 수와 출처
    3. 사용자가 실행할 수 있는 설치 명령어
    4. skills.sh의 자세히 알아보기 링크

    응답 예시:

    I found a skill that might help! The "react-best-practices" skill provides
React and Next.js performance optimization guidelines from Vercel Engineering.
(185K installs)

To install it:
npx skills add vercel-labs/agent-skills@react-best-practices

Learn more: https://skills.sh/vercel-labs/agent-skills/react-best-practices

    6단계: 설치 제안하기

    사용자가 진행하기를 원하면 대신 skill을 설치할 수 있습니다.

    npx skills add <owner/repo@skill> -g -y

    -g 플래그는 전역(사용자 수준)으로 설치하고, -y 플래그는 확인 프롬프트를 건너뜁니다.

    주요 Skill 카테고리

    검색할 때는 다음과 같은 주요 카테고리를 참고합니다.

    카테고리검색어 예시
    웹 개발react, nextjs, typescript, css, tailwind
    테스트testing, jest, playwright, e2e
    DevOpsdeploy, docker, kubernetes, ci-cd
    문서화docs, readme, changelog, api-docs
    코드 품질review, lint, refactor, best-practices
    디자인ui, ux, design-system, accessibility
    생산성workflow, automation, git

    효과적인 검색을 위한 팁

    1. 구체적인 키워드 사용: "testing"만 쓰기보다 "react testing"이 낫습니다.
    2. 다른 표현 시도: "deploy"로 찾지 못하면 "deployment"나 "ci-cd"를 시도합니다.
    3. 인기 있는 출처 확인: 많은 skill이 vercel-labs/agent-skills 또는 ComposioHQ/awesome-claude-skills에서 나옵니다.

    Skill을 찾지 못한 경우

    관련 skill이 없으면 다음과 같이 합니다.

    1. 기존 skill을 찾지 못했다고 알립니다.
    2. 일반적인 역량으로 작업을 직접 돕겠다고 제안합니다.
    3. 사용자가 npx skills init으로 자신의 skill을 만들 수 있다고 안내합니다.

    예시:

    I searched for skills related to "xyz" but didn't find any matches.
I can still help you with this task directly! Would you like me to proceed?

If this is something you do often, you could create your own skill:
npx skills init my-xyz-skill
