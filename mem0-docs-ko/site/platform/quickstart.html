비공식 한국어 번역입니다. 공식 문서가 아닙니다. 원문 · 기준 커밋 ed1f10f · Apache-2.0

빠른 시작

Mem0 Platform 계정을 만들고 SDK를 설치한 뒤 5분 안에 첫 메모리를 저장합니다.

약 5분이면 API 키를 발급받고, 첫 메모리를 저장하고, 다시 검색할 수 있습니다. Python, JavaScript, cURL, 터미널 중 하나로 따라 하세요.

참고

AI 에이전트인가요? 에이전트로 가입하기를 참고하세요. 이메일이나 대시보드 없이 명령 4개로 동작하는 API 키를 만들 수 있습니다.

사전 요구 사항

  • Mem0 Platform 계정(여기에서 가입)
  • API 키(대시보드에서 발급)
  • Python 3.10+, Node.js 18+ 또는 cURL. CLI에는 Node.js 18+ 또는 Python 3.10+가 필요합니다.

첫 메모리 저장하기

  1. 설치

    탭을 하나 고른 뒤 아래 모든 단계에서 같은 탭을 사용하세요.

    Python

    pip install mem0ai

    JavaScript

    npm install mem0ai

    cURL

    # Nothing to install. cURL ships with macOS and most Linux distributions.

    CLI

    npm install -g @mem0/cli
# or, if you prefer Python: pip install mem0-cli

  2. API 키 설정

    Python

    from mem0 import MemoryClient

client = MemoryClient(api_key="your-api-key")

    JavaScript

    import MemoryClient from 'mem0ai';
const client = new MemoryClient({ apiKey: 'your-api-key' });

    cURL

    export MEM0_API_KEY="your-api-key"

    CLI

    mem0 init --api-key "your-api-key"

  3. 메모리 추가

    Python

    messages = [
    {"role": "user", "content": "I'm a vegetarian and allergic to nuts."},
    {"role": "assistant", "content": "Got it! I'll remember your dietary preferences."}
]
client.add(messages, user_id="user123")

    JavaScript

    const messages = [
    {"role": "user", "content": "I'm a vegetarian and allergic to nuts."},
    {"role": "assistant", "content": "Got it! I'll remember your dietary preferences."}
];
await client.add(messages, { userId: "user123" });

    cURL

    curl -X POST https://api.mem0.ai/v3/memories/add/ \
  -H "Authorization: Token $MEM0_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Im a vegetarian and allergic to nuts."},
      {"role": "assistant", "content": "Got it! Ill remember your dietary preferences."}
    ],
    "user_id": "user123"
  }'

    CLI

    mem0 add "I'm a vegetarian and allergic to nuts." --user-id user123

    Mem0는 대화에서 개별 사실을 뽑아내 각각 따로 저장합니다.

    {
  "results": [
    {"id": "0f2c1b6e-9a3d-4b18-8f77-1c2d3e4f5a6b", "memory": "Is a vegetarian", "event": "ADD"},
    {"id": "14e1b28a-2014-40ad-ac42-69c9ef42193d", "memory": "Allergic to nuts", "event": "ADD"}
  ]
}

  4. 메모리 검색

    Python

    results = client.search("What are my dietary restrictions?", filters={"user_id": "user123"})
print(results)

    JavaScript

    const results = await client.search("What are my dietary restrictions?", { filters: { user_id: "user123" } });
console.log(results);

    cURL

    curl -X POST https://api.mem0.ai/v3/memories/search/ \
  -H "Authorization: Token $MEM0_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What are my dietary restrictions?",
    "filters": {"user_id": "user123"}
  }'

    CLI

    mem0 search "What are my dietary restrictions?" --user-id user123

    두 사실이 질문과 일치하는 정도에 따라 순위가 매겨져 반환됩니다.

    이 메모리를 모델에 컨텍스트로 전달하면, 모델은 사용자에게 다시 묻는 대신 이미 아는 내용을 바탕으로 답합니다.

팁

add와 search를 직접 호출하는 대신 Mem0를 도구 모음으로 에이전트에 넘겨, 언제 저장하고 조회할지 에이전트가 결정하게 할 수도 있습니다. Mem0 MCP를 참고하세요.

user_id의 실제 역할과, 위에서 비어 있던 agent_id, app_id, run_id 필드를 설명합니다.

Mem0의 동작 방식

한 문장이 왜 메모리 두 개가 되었는지, Mem0가 무엇을 보관할지 어떻게 결정하는지 설명합니다.

메모리 업데이트와 삭제

저장된 사실이 바뀌거나 오래되었을 때 쓰는, add와 search 외의 작업을 다룹니다.
